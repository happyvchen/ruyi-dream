# brand-analysis/ — Agent Guide

## 职责 (Scope)

本目录存放 Lily 历史真实图的品牌调性分析素材，例如抽样接触表和临时抽样图片。这里是品牌模板沉淀的素材区，不是权威设计文档区。

## 文件说明

| 路径 | 内容 | 使用方式 |
|---|---|---|
| `lily-real-sample-contact-sheet.jpg` | Lily 历史真实图抽样接触表 | 可作为品牌调性分析和模板初始化参考 |
| `tmp/` | 抽样过程中的临时图片 | 仅供追溯，不作为正式模板清单 |

## 本地规则 (Local Rules)

- 品牌调性的权威文字规范在 `../design/02_brand_and_assets/lily_brand_style_templates.md`。
- 本目录图片可作为分析输入，但分析结论必须沉淀到 `../design/02_brand_and_assets/` 后才成为实现依据。
- 清理、覆盖、移动 `tmp/` 或接触表前必须获得用户确认。
