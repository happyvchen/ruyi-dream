# 品牌信息 Prompt 实施样例

> 本文是 0.1.0 实施阶段可参考的 Prompt 样例，不是系统 seed 默认值。上线实施时应在 `Prompt 维护` 中按客户现场确认后填写。

```text
- 品牌定位：
LILY 是中国“商务时装”定位的代表品牌之一。它不是传统职业制服，而是把时尚带入商务、都市生活和轻社交场景的现代女装。品牌表达应围绕轻松高级、自信、美丽、不费力，能在工作与生活之间自然切换

- 品牌审美关键词：
轻松高级、现代简洁、清爽明亮、干净廓形、智性优雅、女性力量、柔中带利落、精致但不沉重、商务场合可穿但不办公室化

- 造型原则：
优先判断整套 look 是否好看、是否符合 LILY 的商务时装调性、是否有电商 Lookbook 的商业吸引力。搭配服装库是可选资源，不是必须使用。连衣裙、套装、连体类、强设计单品通常已经是完整 look，默认不需要再从服装库选择上装、外套、马甲或下装；可以通过鞋、包、首饰、发型、姿态、镜头和棚拍气质完成品牌表达。可接受自然层次关系，但主要审美逻辑应来自整体好看、品牌成立和商业吸引力

- 商品与拍摄：
采用商品导向的 commercial lookbook / e-commerce fashion photography。背景以米白、浅灰、纯净棚拍或极简都市空间为主。光线柔和、低反差、真实肤色，姿态自然、自信、从容、克制，可有轻斜正、轻走动、插袋、侧身、回身等生活化动势。整组镜头需要让主推款足够可识别，并覆盖整体轮廓、穿着效果、关键细节和材质质感

- 配饰边界：
鞋、包、首饰是风格辅助，可省略。确有必要时应轻体量、弱道具感、克制精致；可以增加时髦度和生活感，但不得成为第二主角或传统办公室功能道具

- 负向约束：
避免传统职业制服感、银行柜员式职业装、僵硬办公室套装、功能性办公道具、过强权威感、过重体量感、过度成熟沉重、甜美少女感、网红写真感、街头潮流感、夸张时装大片感、强戏剧光、高冷奢侈品大片、复杂背景、浓妆、攻击性姿态、过度配饰、面料质感不真实

```
