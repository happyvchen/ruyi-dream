# Ruyi-Dream 用户使用教程

本文面向日常使用 `Ruyi-Dream` 的用户，帮助你完成一次从主推款上传到电商棚拍成片的生产流程。

你不需要写复杂指令，也不需要理解模型设置。日常操作只围绕服装、搭配、拍摄和结果确认。

## 1. 快速开始

一次完整生产通常按下面顺序完成：

```text
维护搭配服装库
-> 进入 AI 摄影棚
-> 上传主推款
-> AI 智能选搭
-> 生成拍摄剧本
-> 生成分镜预览
-> 生成成片
-> 下载结果或查看生成记录
```

如果你已经准备好主推款和搭配服装库，也可以在 `AI 摄影棚` 上传主推款后点击页面顶部的 `一键成片`。系统会自动完成所有步骤。

## 2. 使用前准备

### 2.1 准备主推款图片

主推款是本次要重点展示的商品。最多 8 张。

推荐图片顺序：

1. 正面全貌
2. 背面或侧面
3. 细节、面料、腰头、领口、袖口、裤脚等重点部位

图片排序会影响系统理解商品。上传后可以拖动排序、删除或更换图片。

### 2.2 准备搭配服装库

`搭配服装库` 里的服装会作为真实可见的搭配服装进入最终图。当前只支持服装类素材，不支持鞋、包、饰品入库。

导入规则：

- 散图 = 一套搭配服装
- 一个文件夹 = 一套搭配服装
- 多个一级文件夹 = 多套搭配服装
- 单套最多 6 张

导入后，系统会识别服装标签。只有状态为 `可用` 的搭配服装才会进入智能选搭。

### 2.3 查看模特与背景

`模特与背景` 页面用于查看当前默认模特和拍摄背景参考。现阶段用户不需要选择模特，也不需要维护模特；系统会在生成时自动使用当前默认模特快照。

## 3. AI 摄影棚完整流程

`AI 摄影棚` 是主要生产入口，固定分为五步：

```text
上传主推款 -> AI 智能选搭 -> 生成拍摄剧本 -> 生成分镜预览 -> 生成成片
```

### 3.1 上传主推款

进入 `AI 摄影棚` 后，先上传本次主推款图片。上传图片后，系统会自动创建草稿任务，避免中途丢失。

你可以做这些操作：

- 修改任务名
- 上传主推款散图或文件夹
- 拖动调整图片顺序
- 删除或更换图片

如果 AI 对主推款的理解不符合服装事实，优先回到上传阶段调整参考图顺序或删除误导图片。

### 3.2 AI 智能选搭

点击 `AI 智能选搭` 后，系统会理解主推款，并从 `搭配服装库` 中选择真正服务主推款的搭配服装。

如果不满意，可以在右侧当前步骤要求中写一句简短要求，然后点击 `重新选搭`。例如：

```text
不要外套，改成更轻盈、更时尚的搭配。
```

重新选搭成功后，后续拍摄剧本、分镜预览和成片需要基于新方案重新生成。

### 3.3 生成拍摄剧本

选搭完成后，点击 `生成拍摄剧本`。系统会把推荐造型方案转成拍摄前可执行的剧本，包括整体导演设定和 6 个镜头方案。

如果不满意，可以在右侧当前步骤要求中填写拍摄要求，然后点击 `重新生成拍摄剧本`。例如：

```text
增加更明确的裤脚展示，整体不要太街头，保持高级感。
```

重新生成剧本成功后，旧分镜预览和旧成片会失效。

### 3.4 生成分镜预览

点击 `生成分镜预览` 后，系统会根据当前拍摄剧本生成一张 3:2 分镜预览图。

如果不满意，可以填写当前步骤要求并点击 `重新生成分镜预览`。重新生成预览成功后，旧成片会失效。

### 3.5 生成成片

点击 `生成成片` 后，系统会并发生成前 5 张最终成片。每张图有独立状态，成功后可以单张下载。

如果整组不满意，可以填写成片生成要求并点击 `重新生成成片`。如果只有单张不满意，可以对单张重新生成，不影响其他已成功图片。

当前版本支持单张下载。

## 4. 一键成片

`一键成片` 适合想快速完成整条链路的场景。

点击后，系统会自动执行：

```text
AI 智能选搭 -> 生成拍摄剧本 -> 生成分镜预览 -> 生成成片
```

## 5. 搭配服装库

`搭配服装库` 用于维护真实会进入最终图的搭配服装。

### 5.1 导入搭配服装

进入 `搭配服装库` 后，点击导入入口，选择图片或文件夹。

导入时注意：

- 同一套服装的图片放在一起。
- 单套不要超过 6 张。
- 图片尽量清晰，避免过度遮挡、滤镜、低清晰度。
- code 尽量使用团队内部容易识别的货号或名称。

导入后，系统会先保存图片，再进行标签识别。图片保存完成后，即使识别还没结束，也不会丢失本次导入数据。

### 5.2 查看状态

搭配服装常见状态：

- `草稿`：已创建但还未完成识别。
- `正在打标`：系统正在识别服装信息。
- `待复核`：识别结果需要人工确认，暂不进入智能选搭。
- `可用`：可以进入智能选搭。
- `打标失败`：识别失败，可以重试。

只有 `可用` 状态的搭配服装会被 AI 摄影棚使用。

### 5.3 编辑搭配服装

你可以在详情中：

- 修改 code
- 查看或放大图片
- 调整图片顺序
- 删除、替换或追加图片
- 查看识别出的标签信息

如果修改了图片或排序，系统会提示这次修改可能影响识别结果。你可以选择仅保存，或保存后重新识别。

### 5.4 归档搭配服装

不再希望被选搭的服装，可以归档。归档后它会从日常列表隐藏，也不会影响已经生成过的历史记录。

谨慎执行删除类操作。删除素材可能影响相关任务和文件，遇到不确定情况时先联系项目维护人员确认。

## 6. 模特与背景

`模特与背景` 页面只用于查看当前默认模特信息和拍摄背景参考，包括名称、参考图和基础说明。

## 7. 生成记录

`生成记录` 用于查看历史拍摄任务、继续未完成任务和复盘结果。

列表中通常可以看到：

- 任务名
- 状态
- 创建时间
- 主推款缩略图
- 选中搭配服装摘要
- 分镜预览或最终图缩略图

常见操作：

- 点击记录主体：查看记录详情。
- 点击 `查看进度`：回到运行中的任务。
- 点击 `继续生成`：恢复未完成任务。
- 点击 `再次生成`：回到已完成任务，由你在 AI 摄影棚中确认下一次生成动作。

## 8. 结果不满意时怎么办

根据问题出现的位置选择重试步骤：

| 问题 | 建议操作 |
|---|---|
| 主推款图片不清楚、顺序不对 | 回到上传主推款，调整图片后重新选搭 |
| 搭配方向不合适 | 查看 `搭配服装库` 是不是确实没有更合适的搭配？如果是则先补充 `搭配服装库` 中的素材；如果不是，则填写智能选搭要求并点击 `重新选搭` |
| 搭配可以，但镜头、姿势、展示重点不合适 | 填写拍摄剧本要求并点击 `重新生成拍摄剧本` |
| 剧本可以，但分镜整体感觉不对 | 填写分镜预览要求并点击 `重新生成分镜预览` |
| 只有某一张最终图不好 | 对单张成片重新生成（抽卡） |
| 多张最终图都不好 | 填写成片生成要求并点击 `重新生成成片` |
| 任务中途失败 | 重试当前失败步骤，或点击 `一键成片` 从断点继续 |

填写要求时尽量使用清楚的业务语言，例如：

```text
主推款是轻薄夏季上衣，不要厚重外套，整体更清爽。
```

```text
重点展示腰头和裤脚，避免坐姿遮挡裤型。
```

```text
搭配更时尚，不要过度甜美。
```

## 9. 当前版本限制

暂不支持：

- 普通用户手动替换搭配服装
- 鞋、包、饰品作为商品级素材入库
- 批量 ZIP 下载
- 平台命名和规格导出
- 自定义选择第几个分镜生成成片
- 普通用户编辑底层生成指令、模型设置或调用详情
- 普通用户维护模特与背景

当前固定生成前 5 张最终成片。第 6 格分镜仅作为剧本和预览结构的一部分，不生成最终图。

## 10. 推荐工作习惯

- 主推款图片先按“全貌 -> 侧背 -> 细节”排序。
- 阶段要求写事实和重点，不写长指令。
- 搭配服装库保持 `可用` 状态服装质量稳定，减少低清晰度或重复图片。
- 每一步先看结果是否解决当前问题，再决定是否重试。
- 重新生成上游步骤前，先确认是否接受后续结果失效。
- 重要任务完成后，到 `生成记录` 里确认最终图和过程记录都能正常查看。
