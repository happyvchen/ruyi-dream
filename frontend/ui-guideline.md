# Frontend UI Guideline

## 核心原则

- 用户看到的是拍摄任务，不是 AI 管线。
- 默认只展示：服装、默认组图方案、Lily 风格摘要、生成结果。
- 高级信息折叠展示，调试信息默认隐藏。

## 页面布局

当前 MVP 采用分工明确的两类工作台：

1. `服装素材`：上传/编辑图包，维护素材图片，生成或更新默认组图方案。
2. `生成组图`：选择货号，直接使用默认组图方案生成，查看结果并重生/导出。

上传预览和已保存素材的服装图片卡片必须保持一致：

- 使用统一的卡片边框、缩略图比例、文件名排版和删除按钮位置。
- 展示文件名、图片尺寸、文件大小。
- 不展示“主参考/参考图/正面图/3D 图”等图片角色标签。
- 默认第一张图片作为封面，该规则在说明文案中提示，不作为用户需要维护的字段。

## 文案规则

使用：

- 首图
- 全身
- 半身
- 背面
- 侧身
- 局部
- 生成
- 重生
- 保留
- 导出

避免默认展示：

- prompt
- task package
- Image 2 参数
- provider
- seed
- adapter

## 状态规则

| 状态 | 用户文案 |
|---|---|
| `DRAFT` | 待确认 |
| `CONFIRMED` | 已确认 |
| `QUEUED` | 排队中 |
| `RUNNING` | 生成中 |
| `SUCCEEDED` | 已生成 |
| `FAILED` | 生成失败 |

| 业务状态 | 用户文案 |
|---|---|
| 有默认组图方案 | 已保存默认方案 |
| 无默认组图方案 | 缺少默认方案 |
| `GarmentSku.NEW` | 待策划 |
| `GarmentSku.ANALYZED` | 已策划 |
| `GarmentSku.CONFIRMED` | 已确认 |

## 高级设置

高级设置可以包括：

- 尺寸增强
- 拍摄角度微调
- 补充要求
- 风格参考说明

这些设置默认折叠，不阻塞默认生成流程。
