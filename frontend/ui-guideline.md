# Frontend UI Guideline

## 核心原则

- 用户看到的是拍摄任务，不是 AI 管线。
- 默认只展示：主推款、搭配服饰、六宫格预览、最终成片、生成记录。
- 普通用户界面不展示底层模型名称、调用参数、请求快照、返回快照和调试 JSON。

## 页面布局

当前 MVP 采用分工明确的工作台：

1. `AI 摄影棚`：上传主推款，完成智能选搭、六宫格预览和成片生成。
2. `搭配服饰库`：导入和管理真实配角服装，导入后系统默认打标。
3. `数字模特`：只读展示当前默认模特。
4. `生成记录`：查看进入过生成阶段的任务、入参信息、选搭、预览和结果。

## UI 语义

前台核心对象统一叫 `主推款`、`搭配服饰` 和 `拍摄任务`。`搭配服饰` 是会真实出现在最终图里的配角服装，不叫素材包。

推荐：

- 页面入口：`搭配服饰库`
- 列表对象：`搭配服饰`
- 上传动作：`导入搭配服饰`
- 单张图片：`服饰图片`
- 计数：`N 套`、`N 张图片`

避免：

- 用 `图包`、`素材包`、`货号图包` 作为新版库页主语义。
- 让普通用户看到或编辑 prompt、provider 参数、模型名称、调用快照或人工标签 JSON。

搭配服饰详情：

- 列表卡只显示标签摘要，详情抽屉展示完整 `AI 识别标签`、`生效标签`、`人工业务标签`、`官方标题信息` 和 `标签元信息`。
- 标签详情只展示业务可读字段和值，不展示原始 JSON。
- 底层打标调用详情、请求参数、prompt、图片输入元数据、返回结果和失败信息不进入普通用户界面。
- `TAGGING_READY` 显示为 `待复核`，并允许重新识别标签；仅 `READY` 表示可进入选搭。

上传预览和已保存素材的服装图片卡片必须保持一致：

- 使用统一的卡片边框、缩略图比例、文件名排版和删除按钮位置。
- 展示文件名、图片尺寸、文件大小。
- 不展示“主参考/参考图/正面图/3D 图”等图片角色标签。
- 默认第一张图片作为封面，该规则在说明文案中提示，不作为用户需要维护的字段。

图片展示按实际 UI 尺寸选择档位：

- 列表、卡片、缩略图和结果网格使用 `thumbUrl`。
- 弹窗预览和详情大图使用 `previewUrl`。
- `originalUrl` 只用于下载、导出、AI 输入和必要质检，不作为普通列表或弹窗默认图片。
- 轮询刷新时，如果图片对象 key 未变化，不主动替换 `src`，避免浏览器重复下载、解码和重绘。

## 文案规则

使用：

- 首图
- 全身
- 半身
- 背面
- 侧身
- 局部
- 拍摄方案
- 分镜预览
- 最终组图
- 生成
- 重新生成
- 设为最终
- 取消最终
- 导出组图

避免默认展示：

- prompt
- task package
- Image 2 参数
- provider
- Gemini / Image-2 / fal / toapis 等底层模型或供应商名称
- seed
- adapter

避免混用：

- `默认方案` / `确认方案` / `拍摄方案` 指同一业务概念时，统一写 `拍摄方案`。
- `重生` / `重新预览` / `重新生成分镜` 指重新生成动作时，统一写 `重新生成` 或 `重新生成分镜预览`。
- `最终图` 不写成 `候选`、`可用`、`已确认` 等内部评审状态。

## 控件语义

相同业务语义必须使用同一套控件，不按页面临时拼样式。

- 页面顶部的统计、筛选和计数使用统一的工具条或指标条。
- `显示已归档` 使用筛选控件；货号数、任务数、已策划数使用指标卡或计数胶囊。
- `归档` 是日常整理动作，使用中性次级样式。
- 只有会删除文件、删除关联记录或不可逆破坏数据的操作，才使用危险样式。
- 归档/删除弹窗底部操作统一右对齐：取消为次级按钮，默认归档为主按钮；勾选删除关联文件后，主操作才升级为危险按钮。
- 结果图卡默认只保留 `重新生成`、`设为最终` / `取消最终`。不展示候选、可用、需精修或质量原因选择。

## 生成记录

生成记录以任务为主，不以事件日志为主。

列表展示：

- 缩略图
- 货号
- 任务状态
- 完成张数
- 最终图数量
- 重新生成次数
- 创建时间

详情展示：

- 本次入参信息
- 每个图位的当前输出
- 每个图位的当前成片和重新生成记录
- 分镜预览与最终成片

生成组图页右侧的生成记录是紧凑概览。点击后应直接在生成组图页恢复历史任务，而不是跳到生成记录页。

如需内部排查 prompt、任务文本、provider 摘要，应放在后台或工程调试入口，不进入普通用户前台。

## URL 规则

支持：

```text
/generate
/generate?sku={sku}
/generate?run={runId}
/garment-skus/{sku}
/model-profiles/{modelId}
/generation-runs/{runId}
```

核心对象切换要同步 URL，方便刷新恢复和分享。弹窗、折叠、hover、临时上传草稿不进入 URL。

## 状态规则

| 状态 | 用户文案 |
|---|---|
| `DRAFT` | 待确认 |
| `CONFIRMED` | 已确认 |
| `QUEUED` | 排队中 |
| `RUNNING` | 生成中 |
| `SUCCEEDED` | 已生成 |
| `FAILED` | 生成失败 |

| 业务状态 | 用户文案 |
|---|---|
| 有拍摄方案 | 已生成拍摄方案 |
| 无拍摄方案 | 缺少拍摄方案 |
| `GarmentSku.NEW` | 待策划 |
| `GarmentSku.ANALYZED` | 已策划 |
| `GarmentSku.CONFIRMED` | 已确认 |

## 高级设置

高级设置可以包括：

- 尺寸增强
- 拍摄角度微调
- 补充要求
- 风格参考说明

这些设置默认折叠，不阻塞默认生成流程。
