# Frontend UI Guideline

## 核心原则

- 用户看到的是拍摄任务，不是 AI 管线。
- 默认只展示：服装、模特、组图方案、Lily 风格摘要、生成结果。
- 高级信息折叠展示，调试信息默认隐藏。

## 页面布局

主工作台建议采用三段式：

1. 左侧/顶部：当前货号、模特、Lily 风格摘要
2. 中间：组图方案和生成结果
3. 右侧/抽屉：单张图位调整、重生、导出设置

## 文案规则

使用：

- 首图
- 全身
- 半身
- 背面
- 侧身
- 局部
- 生成
- 重生
- 保留
- 导出

避免默认展示：

- prompt
- task package
- Image 2 参数
- provider
- seed
- adapter

## 状态规则

| 状态 | 用户文案 |
|---|---|
| `DRAFT` | 待确认 |
| `CONFIRMED` | 已确认 |
| `QUEUED` | 排队中 |
| `RUNNING` | 生成中 |
| `SUCCEEDED` | 已生成 |
| `FAILED` | 生成失败 |

## 高级设置

高级设置可以包括：

- 尺寸增强
- 拍摄角度微调
- 补充要求
- 风格参考说明

这些设置默认折叠，不阻塞默认生成流程。
