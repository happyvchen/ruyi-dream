## 2. 相比 v2 的改善

### 2.1 模特身份

明显更接近 `Face-01`：

- 短发长度接近
- 刘海形态接近
- 脸型、眼睛、鼻子和冷静表情更稳定
- 5 张之间身份一致性更高

原因：

- 本轮单独强化了 `Face-01` 多角度头部图作为身份源。
- 没有用泛化的 “young female model” 描述替代身份事实。

### 2.2 姿势

比 v2 更接近 Lily 真实图：

- 正面图是克制站姿，不是夸张时装 pose。
- 侧身图接近真实图 02 的走动感。
- 背面图接近真实图 04 的站姿。
- 半身图构图更像真实上半身细节图。

原因：

- 本轮使用同款真实图作为 Pose 边界。
- 组图策划层提前决定每张图的图位和动作，而不是让 Image 2 自己猜。

### 2.3 鞋履与搭配

鞋子比 v2 更接近 Lily：

- 主要生成黑色轻便凉鞋/低存在感鞋。
- 没有出现老气尖头职业鞋。
- 没有出现厚底鞋、运动鞋或复杂夸张鞋。

原因：

- 本轮把鞋履归入 `品牌调性模板 + 同款真实参考图`，而不是靠文字白名单。
- Image 2 的自由度被限制在真实图风格以内。

### 2.4 裙长与裙摆

裙长、裙摆比 v2 更接近真实图：

- 没有变成长裙。
- 裙摆没有变成大伞摆。
- 蓝白条纹下摆露出较明确。
- 侧身和背面保持了短款比例。

原因：

- 商品事实卡中明确标记 `短款`、`轻A/直筒`、`禁止放大裙摆`。
- 同款真实图作为裙长和裙摆视觉边界。

## 3. 仍然存在的问题

### 3.1 服装细节仍有轻微漂移

部分图中蓝白条纹荷叶边的纹理和褶量与真实图并非完全一致。

根因：

- 目前仍是视觉参考约束，不是精确服装重建。
- 没有基于服装结构的分割、贴图或版片约束。

后续方向：

- 增加服装关键细节局部图的强绑定。
- 对袖窿、下摆、背中线分别建立局部约束。

### 3.2 裙长还不是尺寸级可控

本轮接近真实图，但仍然不是严格按厘米控制。

根因：

- 当前没有模特真实身高、腿长、服装衣长、下摆宽等尺寸。
- 只能靠同款视觉参考和提示边界降低漂移。

后续方向：

- 启用尺寸可选增强模块。
- 将 `衣长/裙长/下摆宽/穿着尺码` 转换成视觉比例字段。

### 3.3 本轮仍是组图预览生成

虽然已经按单张任务包设计，但实际为了快速验证，先生成一张 5 图位接触表，再切图。

生产环境中应改为：

- 每张图独立调用 Image 2。
- 第一张确认后作为后续一致性参考。
- 单张失败只重生单张。

## 4. 本轮验证结论

新版产品设计方向成立：

```text
同款真实参考图 + 品牌模板边界 + 组图策划任务包 + 短 prompt
```

相比直接长 prompt 或全品类参考图，本轮在以下方面明显更稳：

- 脸部一致性
- Lily 姿势语言
- 鞋履搭配
- 裙长与裙摆比例
- 组图结构

但要达到真实摄影级别，还需要继续补两个能力：

1. 尺寸可选增强模块，用于精确控制裙长、裤长、下摆宽度。
2. 单张逐图生成 + 已确认图回灌，用于进一步提高整组一致性。
