# V2 本轮短提示词策略

## 总原则

本轮不再用长文本复述服装细节，而是使用“图片角色 + 优先级 + 单张镜头任务”的短提示词。

核心句：

```text
Garment images are the source of truth for exact clothing design, color, fabric, construction, length, hem width, and proportions.
Model head images are the source of truth for identity, hairstyle, face, and expression.
Lily real-photo reference sheet defines brand mood, pose language, footwear/bag/accessory boundary, lighting, background, and composition.
```

## Shot 01

```text
Task: Generate one Lily e-commerce model photo for shot 01: front full-body hero.

Priorities:
1. Preserve the model identity from the head references.
2. Preserve garment facts from the garment references.
3. Follow Lily real-photo references for relaxed urban e-commerce styling and pose.
4. Create a clean vertical full-body product image.

Shot: front full-body view, relaxed Lily standing pose with natural weight shift, full garment visible, above-knee wearing length, restrained slight A-line width.

Measurements: not provided; infer wearing length and proportions from garment images only.
```

## Shot 02

```text
Task: Generate one Lily e-commerce model photo for shot 02: side / three-quarter full-body.

Shot: full-body three-quarter / side walking-feel pose, natural weight shift, one leg slightly forward, arms relaxed, head slightly turned.

Measurements: not provided; infer from garment images only.
```

## Shot 03

```text
Task: Generate one Lily e-commerce model photo for shot 03: upper-body detail with identity.

Shot: vertical upper-body crop from head to upper skirt area, relaxed slight three-quarter pose, calm expression.
```

## Shot 04

```text
Task: Generate one Lily e-commerce model photo for shot 04: back view.

Shot: vertical full-body back view, relaxed natural stance, slight weight shift. Keep visible back center seam/zipper.
```

## Shot 05

```text
Task: Generate one Lily e-commerce model photo for shot 05: garment detail crop.

Shot: vertical close-up crop on the dress worn on body, focusing on either armhole ruffle or hem ruffle plus black fabric texture.
```
