## 相比 V1 的改善

### 1. 面部一致性明显改善

V1 的脸更像“短发女模特泛化结果”，V2 因为单张生成并强化了 `Model Head = identity source of truth`，脸、发型、刘海、耳饰更接近 `Face-01`。

### 2. 服装结构更稳定

V2 五张图中基本保留了：

- 黑色无袖主体
- 蓝白条纹袖窿装饰
- 蓝白条纹下摆
- 背面中线/拉链
- 轻 A 字廓形

### 3. 单张镜头更适合产品化

相比 V1 的 5 宫格图，V2 的每张图都可独立查看、重生、导出，更符合产品流程。

## 仍然存在的问题

### 1. 鞋履仍偏老气

虽然使用了 Lily 品牌调性抽样板，但因为当前参考图是全品类抽样，里面包含不少通勤单鞋/尖头鞋，模型仍然生成了偏尖头职业感的鞋。

结论：

`品牌调性模板不能只用全品类抽样，必须支持同品类/同场景参考图优先。`

针对本款连衣裙，下一轮应使用：

- 连衣裙真实图
- 短裙/无袖裙真实图
- 轻松凉鞋/低存在感鞋履参考
- 侧身走动感参考

而不是全品类混合参考。

### 2. Pose 有改善但还不够 Lily

侧身图比 V1 不那么僵，但首图仍接近普通站姿。说明只靠“relaxed Lily pose”不够，产品里需要真正的 `Pose Reference` 图片，而不是只靠品牌抽样板。

### 3. 裙长和裙摆仍只能做到近似

V2 比 V1 稍微收敛，但由于没有模特尺寸和服装尺寸，模型仍然只能根据图片推断长度与宽度。要稳定解决，必须启用尺寸可选增强模块。

### 4. 局部图可用性提升

局部图已经比 V1 更像电商细节图，黑色面料和蓝白下摆比例更清楚。但若用于真实商品详情，还需要更严格地对齐原始细节图。

## 产品结论

最新版设计方向是对的：

- 少写服装描述，让图片负责事实
- 单张生成优于 5 宫格
- 模特身份锁定有效
- 品牌调性参考有效但需要更细分
- 尺寸模块必须作为可选增强项保留

下一步产品应增加：

1. `同品类品牌参考图自动检索`
2. `Pose Reference 明确绑定`
3. `尺寸增强字段`
4. `每张图的参考图角色清单`
