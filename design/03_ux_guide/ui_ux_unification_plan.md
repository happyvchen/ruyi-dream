# UI/UX 统一优化方案

> 历史方案：其中“四步/分镜预览”流程已被三步直出方案取代。当前实现以 [user_uiux.md](user_uiux.md) 和 `../01_generation_flow/current_generation_workflow.md` 为准；本文仅保留作视觉统一决策记录。

## 背景

Ruyi-Dream 0.1.0 已经具备可用的生产工作台形态，并进入客户使用阶段。下一阶段 UI/UX 优化的目标不是新增业务能力，而是在不改变业务逻辑的前提下，统一 PC 桌面工作台的产品风格、控件心智和页面层级，使产品从“功能完整的后台工具”升级为“安静、专业、美观、易用的 AI 数字化摄影棚”。

本方案用于后续前端改造审核。实现时不得改变 AI 摄影棚四步主流程、接口语义、任务状态机、生成调用边界、Prompt 维护职责和归档/删除策略。

## 设计目标

1. 强化统一性：所有页面使用同一套视觉 token、控件语义、状态表达、图像卡片和筛选/分页规则。
2. 强化生产感：界面像服装视觉团队的摄影工作台，不像 AI 参数控制台，也不像通用后台模板。
3. 强化高级感：整体气质为简约、克制、精密、低调科技；避免夸张装饰、厚重渐变、彩色堆叠和廉价科技风。
4. 强化效率：保留 B2B 生产工具需要的信息密度，主操作明确，批量导入、筛选、继续生成、下载和复盘路径更顺。
5. 强化业务语言：普通用户只看到主推款、搭配服装、拍摄任务、分镜预览、成片和记录；prompt、provider、Request ID、JSON、模型参数只进入 admin 技术详情。

## 设计原则

### 安静优先

默认界面应低噪声，只有生成、继续生成、一键成片等任务推进动作拥有高能视觉。管理动作、筛选、分页、归档、保存、下载等日常动作必须降低视觉饱和度。

### 图像优先

产品的可信度来自真实服装、模特与背景、分镜预览和成片。页面首屏要让图像成为主视觉信号，文字和按钮服务图像判断。

### 层级清晰

用户应能一眼判断：

- 当前在哪个页面；
- 当前任务处于哪一步；
- 下一步应该点哪个主按钮；
- 哪些内容是已生效结果，哪些是待确认草稿；
- 哪些动作只是管理整理，哪些动作会推进生成。

### 克制科技感

科技感来自精密布局、冷静色彩、清晰状态、轻量动效、玻璃/金属般的表面层级和高质量图像，不来自大面积霓虹、发光边框、复杂背景、装饰光球或动态特效。

### 不训练用户写 Prompt

所有用户输入仍使用业务语言：`服装信息`、`智能选搭要求`、`分镜预览要求`、`成片要求`。界面不把普通用户带入 prompt、权重、seed、provider 或模型参数心智。

## 视觉方向

### 产品气质

关键词：

- 安静专业；
- 冷白摄影棚；
- 低调科技；
- 高级电商；
- 精密生产；
- 克制明亮；
- 图像驱动。

不采用：

- 营销 landing page 式超大标题；
- 大面积紫蓝渐变；
- 暗黑霓虹控制台；
- 彩色状态满屏；
- 圆角过大、卡片套卡片；
- 通用 SaaS 后台模板感。

### 色彩系统

色彩应以冷白、中性灰、深墨蓝和少量蓝青为核心。

| 用途 | 建议值 | 说明 |
|---|---|---|
| App 背景 | `#F4F7FB` / `#EEF3F8` | 冷白摄影棚背景，避免纯白刺眼 |
| 主面板 | `rgba(255,255,255,.88)` / `#FFFFFF` | 主要内容表面，可有轻微玻璃感 |
| 次级表面 | `#F7FAFD` | 卡片内部、空状态、弱分区 |
| 深色导航 | `#07111F` / `#0D1726` | 保留产品识别度和低调科技基调 |
| 主文字 | `#0F172A` | 高对比、冷静 |
| 次文字 | `#526174` | 不低于可读对比 |
| 弱文字 | `#7A8797` | 只用于辅助信息 |
| 任务主色 | `#0B7CFF` -> `#10B7C7` | 仅用于生成/继续生成/一键成片 |
| 聚焦色 | `#0EA5E9` | focus ring、选中指示 |
| 成功 | `#0F8A5F` | 可选搭、已完成 |
| 警示 | `#B45309` | 待复核、部分完成 |
| 失败/危险 | `#BE123C` | 生成失败、彻底删除 |

规则：

- 蓝青渐变只给任务推进类动作，不给普通管理按钮。
- 页面内同时出现的高饱和色不超过两类。
- 状态色以浅底深字为主，不用大面积实色块。
- 归档不是危险色；彻底删除才使用危险色。

### 字体与排版

继续使用系统无衬线字体栈，优先依赖 Apple 平台字体质感；暂不引入外部字体，避免网络、授权和部署复杂度。

| 层级 | PC 桌面建议 | 用途 |
|---|---:|---|
| 页面标题 | 28-32 / 1.15 / 700 | 页面主标题 |
| 区块标题 | 18-22 / 1.25 / 700 | 当前步骤、详情分区 |
| 卡片标题 | 14-16 / 1.3 / 700 | 货号、任务名 |
| 正文 | 13-14 / 1.55 / 400 | 摘要、说明 |
| 辅助 | 11-12 / 1.4 / 500 | 时间、计数、meta |

规则：

- 不使用 viewport 宽度缩放字号。
- 不使用负字距。
- 长货号、任务名必须有明确换行或省略规则。
- 表格/列表/卡片内部不使用 hero 级字号。

### 圆角与阴影

| 类型 | 圆角 | 阴影 |
|---|---:|---|
| App 主面板 | 12px | `0 18px 50px rgba(15,23,42,.08)` |
| 卡片/列表行 | 10px | 默认无或极轻，hover 轻微抬升 |
| 输入框/按钮 | 8px | 默认无，任务按钮轻微阴影 |
| 图像缩略图 | 8px | 无，图像自身做主视觉 |
| 胶囊筛选 | 999px | 默认无，打开/选中时轻微边框强调 |

规则：

- 不使用过大的 18px-24px 圆角。
- 页面 section 不做漂浮卡片套卡片。
- hover 不改变布局尺寸，不使用会造成跳动的 scale。

### 动效

动效只服务反馈：

- hover / focus / active：150-220ms；
- 面板打开、抽屉、弹窗：180-260ms；
- 生成中 loading：允许持续动画；
- 装饰元素不做无限动画；
- 必须尊重 `prefers-reduced-motion`。

## 信息架构

### 全局导航

导航保留 PC 桌面深色侧栏，并统一命名和顺序：

1. `AI 摄影棚`
2. `搭配服装库`
3. `模特与背景`
4. `生成记录`
5. `Prompt 维护`（admin-only）

优化方向：

- 侧栏品牌区保留 `Ruyi-Dream`，副标题建议用中文 `AI 数字化摄影棚`，减少中英文混搭。
- active 状态使用低饱和深蓝底 + 左侧或底部细线，不用过亮发光。
- 当前产品不把移动端作为体验目标；小屏幕只保留基础可访问兜底，不进入本轮验收。

### 页面标题区

每个页面顶部固定两类常驻信息：

- 页面标题；
- 页面主操作。

页面短说明作为标题的辅助信息，不常驻占用首屏；当鼠标悬停或键盘聚焦页面标题时，用轻量 tooltip 展示一句业务价值说明。tooltip 只承载短句，不放长规则、低频配置或复杂筛选。筛选进入下方 command bar。

### Command Bar

`搭配服装库` 和 `生成记录` 使用统一 command bar：

- 第一行：搜索 + 主操作/批量操作；
- 第二行：高频筛选 + 排序 + 归档开关；
- 当前产品以 PC 桌面工作台为目标，不设计移动端筛选抽屉。

筛选控件应像工具，不像主按钮。默认中性白底、灰边、深色文字；选中时使用深墨色或极浅蓝底。

## 控件系统

### 任务型按钮

用途：

- `一键成片`
- `继续一键成片`
- `重新一键成片`
- `AI 智能选搭`
- `重新选搭`
- `生成分镜预览`
- `重新生成分镜预览`
- `生成成片`
- `重新生成成片`
- `继续生成`
- `再次生成`
- `查看进度`

视觉：

- 蓝青渐变；
- 白字；
- 左侧 lucide 图标；
- 40-42px 高；
- PC 桌面最小宽度稳定；
- 窄屏只保留基础可访问，不作为当前体验验收范围。

### 管理型按钮

用途：

- 导入、导入、保存、下载、批量管理、归档、恢复、刷新预览、取消、筛选重置。

视觉：

- 中性白底或浅灰底；
- 灰蓝边框；
- 深墨文字；
- hover 只轻微改变边框和背景；
- 不使用蓝青渐变。

### 危险型按钮

用途：

- 彻底删除；
- 删除关联文件；
- 其它不可逆破坏数据。

视觉：

- 红色实底或红色描边；
- 必须搭配确认文案和影响预检；
- 普通归档不能使用危险样式。

### 图标按钮

用途：

- 放大查看；
- 替换图片；
- 移除图片；
- 关闭弹窗；
- 展开/收起；
- 下载单张。

规则：

- 固定 32px 或 36px；
- 必须有 `title` 或 `aria-label`；
- hover 不改变布局；
- 图片角落按钮使用半透明白底，保证图像上可见。

### 状态徽标

状态徽标只表达状态，不承担主操作。

| 状态 | 文案 | 色彩 |
|---|---|---|
| READY | `可选搭` | 绿色浅底 |
| TAGGING_READY | `待复核` | 琥珀浅底 |
| TAGGING_RUNNING | `识别中` | 蓝色浅底 |
| TAGGING_FAILED | `识别失败` | 红色浅底 |
| STYLING_READY | `已选搭` | 蓝色浅底 |
| PREVIEW_READY | `分镜预览完成` | 蓝色浅底 |
| FINAL_PARTIAL | `部分完成` | 琥珀浅底 |
| COMPLETED | `已完成` | 绿色浅底 |

普通用户不展示 `AI 置信度` 字样。可改为：

- `识别可信`;
- `建议复核`;
- `信息不足`;
- `可选搭`;
- `待复核`。

置信度百分比只在详情或 admin 技术信息中出现，普通列表卡片不默认露出。

## 页面方案

### 登录页

现状方向较接近目标，但需要与工作台统一。

优化：

- 保留深色玻璃卡和冷光品牌标识；
- 背景减少装饰光感，避免像营销页；
- 副标题使用 `AI 数字化摄影棚`；
- 输入框、按钮圆角和 focus ring 与工作台一致；
- 登录卡片宽度保持 400-440px；
- 错误提示使用清晰业务文案。

验收：

- 登录页和进入后侧栏在品牌色、R 标识、圆角、按钮上保持一致。

### AI 摄影棚

目标：最重要的生产主入口，像拍摄任务控制台，而不是导入表单。

桌面布局：

- 左侧主工作区 + 右侧任务摘要保持；
- 顶部步骤条更轻，采用水平步骤 rail，active 步骤用细线和深色文字表达；
- 当前步骤内容区域使用更强的主视觉容器；
- 右侧任务摘要不抢主区注意力，保持紧凑。

导入主推款：

- 导入区增加“摄影棚工作台”感：大尺寸虚线容器 + 中性背景 + 图像占位；
- 选择图片、选择文件夹为管理型按钮；
- 导入说明压缩为两行以内，详细规则在清单阶段展示；
- 批次清单出现后，优先展示货号、图片缩略图、数量和服装信息，不让说明文字占据首屏。

AI 智能选搭：

- `StylingPlan` 展示从“文本报告”改为“拍摄方案卡”：
  - 主推款理解；
  - 推荐搭配；
  - 选搭理由；
  - 审美/品牌/商品成立性；
  - 被拒方案摘要。
- 分数或诊断不应像模型评分表，使用业务标签和简短判断。

分镜预览：

- 预览图保持最大展示面积；
- 图下 legend 精简为：`1-5 生成成片`、`6 仅作参考`；
- 放大检查是图像 hover 或图标按钮，不需要长说明。

成片：

- 五张成片采用稳定网格；
- 每张图卡只保留最必要操作：放大、重新生成、下载；
- `下载全部成片` 为管理型按钮；
- `重新生成成片` 为任务型按钮。

右侧任务摘要：

- `任务摘要 / 最近任务` tab 保留；
- 摘要中要求输入模块始终展开，放在主生成动作上方；
- 最近任务行只展示缩略图、货号、状态、创建时间，不展示成片数；
- 当前任务行使用极浅蓝底，不用强边框。

### 搭配服装库

目标：成为 `AI Stylist 可用资产工作台`，让服装团队快速看图、找货号、判断状态、做整理。

桌面布局：

- 顶部标题 + `导入搭配服装` 主管理动作；
- command bar 两行；
- 下面是图片卡网格；
- 分页固定在面板底部，但不得遮挡内容；
- 每页固定提供 `24 / 48 / 96 套`，默认 24 套，不根据视口或卡片高度自动改变分页数量；
- 卡片网格继续响应容器宽度排列，超出当前内容区时只在卡片区内部滚动。

卡片：

- 图片面积优先，建议卡片高度中图片占 55%-65%；
- 图片背景使用冷白，不使用厚阴影；
- 货号加粗；
- 状态徽标位于货号同一行右侧；
- 摘要最多两行；
- 标签最多三枚；
- 默认不展示 `AI 置信度`；
- 底部操作：`详情`、`归档` 使用管理型按钮，视觉降低。

筛选：

- 默认展示：搜索、品类、导入时间、排序、状态、查看已归档、批量管理；
- `查看已归档` 使用开关或 checkbox pill，不像主按钮；
- 筛选打开态使用 PC 桌面 popover，不设计移动端底部抽屉。

详情抽屉：

- 宽度 680-760px；
- 顶部固定货号、状态、主要动作；
- 分区顺序：
  1. 基础信息；
  2. 图片包；
  3. AI 识别标签；
  4. 人工业务标签；
  5. 技术详情（admin 可见，默认折叠）。
- 普通用户不看到 Gemini、provider、Request ID、JSON。

批量管理：

- 批量模式下卡片左上出现 checkbox；
- 底部或顶部出现批量操作条；
- 选择资格与归档状态分离，未归档、已归档和混合结果都可选择及全选；
- 操作条只提供一个 `归档 N 项` 入口，不因混合选择整体禁用；归档、取消归档和彻底删除的实际数量在弹窗选项中分别展示；
- 单条对象也只保留一个 `归档` 入口，不因活动、已归档或部分归档状态改变入口名称，也不在卡片、行或详情区额外放置取消归档、删除或彻底删除按钮；
- 统一弹窗用单选项渐进展示归档、取消归档和彻底删除；默认选中可逆且符合当前状态的操作，只有选中彻底删除后才显示影响预检、业务名称确认和危险色提交按钮；
- 识别中、生成中等对象可以参与下载等只读批量操作，但不计入归档数量；`deletion_pending` 等无可用动作的处理中对象禁选并说明原因；
- 用户看到的每个带复选框的行或卡片都是完整选择对象，点击、Shift 连选、框选和全选必须命中同一集合；批次 / 分组行不得因底层需要异步读取子项而被框选跳过；
- 批次 / 分组复选框使用选中、未选、部分选中三态，选择批次表示选择其全部可操作子项，禁选子项不参与三态和数量计算；
- 框选拖动阶段即时高亮可见目标，松开后原子解析实际业务对象；解析失败回滚本次选择并保留此前结果，不允许部分提交；
- 操作按钮与底部选择数量统计实际受影响的业务对象，不把一条批次行误报成一个任务；
- 框选 / Shift 连选说明放入 `全选本页` 的悬浮和键盘聚焦提示，不在顶部操作区常驻占位；禁用态也保留可聚焦的说明入口，生成记录按当前视图区分单条、批次和混合记录文案；
- 固定底部分页栏在批量模式持续展示已选数量，按页面分别使用“套 / 条 / 个任务”，零选择也显示；生成记录以实际任务数为准，并向辅助技术动态播报；
- 切换筛选、分页、归档视图时清空选择。

### 模特与背景

目标：作为视觉质量标杆页面，突出模特与背景参考的图像质量。

优化：

- 保留大图左侧、参考图右侧的结构；
- 页面标题补一句说明：`当前拍摄任务默认使用此模特身份与背景参考`；
- 头部参考图和背景参考图统一使用图片卡；
- `只读` 徽标弱化，不抢标题；
- 背景参考图说明压缩，长规则进入 tooltip 或辅助说明。

### Prompt 维护

目标：admin-only 技术页面，但仍属于同一产品，而不是另一个编辑器系统。

桌面布局：

- 三栏结构保留：槽位导航 / 编辑区 / 预览工具；
- 右侧预览常开；
- 顶部操作：`刷新预览`、`保存`；
- dirty 状态清晰提示。

视觉：

- 槽位卡片使用同一 panel/card token；
- 编辑区 textarea 使用更稳的 monospace、行高、边框；
- 预览区使用深色代码块可以保留，但要减少过重阴影；
- admin 徽标使用小号浅蓝 pill。

文案：

- 页面标题仍为 `Prompt 维护`，因为这是 admin 页面；
- 普通用户永远不展示该入口；
- 预览只说 `本地预览`，明确不触发模型调用。

### 生成记录

目标：拍摄记录工作台，支持按任务或批次复盘、继续、下载和归档。

桌面布局：

- 左侧记录列表 + 右侧详情保持；
- 记录列表的行主体负责查看详情；
- 行尾只保留一个任务型按钮和一个弱管理动作；
- 批次记录视觉与单次记录一致，但使用缩略图组和聚合徽标。

列表行：

- 缩略图 50-56px；
- 货号/任务名；
- 状态 + 日期；
- 成片缩略条；
- 主操作：`继续生成` / `再次生成` / `查看进度`；
- 次操作：`归档` 可降为图标或更多菜单。

详情空状态：

- 当前空状态保留，但视觉更轻；
- 文案：`选择一条记录`、`查看分镜预览、搭配服装和最终成片`。

批次：

- 批次卡展示最多 4 张缩略图；
- 聚合状态用业务文案；
- `展开` 为管理型按钮；
- 批次详情中支持批次内搜索和失败优先。

### PC 桌面适配范围

当前产品是给视觉生产团队使用的 PC 桌面工作台，本轮只对桌面体验负责。

桌面基线：

- 主要验收宽度：`1440px`、`1512px`、`1728px`、`1920px`；
- 允许最低工作宽度：`1280px`；
- 全局侧栏常驻，页面不切换到移动顶部导航；
- `AI 摄影棚` 保持主工作区 + 任务侧栏；
- `搭配服装库` 保持搜索、筛选、批量管理、卡片网格、分页同屏可见；
- `生成记录` 保持记录列表 + 详情侧栏；
- admin 页面保持多栏生产效率布局。

窄屏兜底：

- 低于 PC 工作宽度时，仅保证内容不被完全遮挡；
- 不设计移动端独立交互；
- 不把 390px、768px 等移动断点作为当前产品验收项；
- 不新增移动端筛选抽屉、移动详情页或移动专用导航。

## 技术实现边界

本次 UI/UX 统一优化不得改变：

- 后端 API；
- 任务状态机；
- 生成/打标/provider 调用时机；
- Prompt 槽位语义；
- 媒体存储策略；
- 归档/彻底删除业务规则；
- user/admin 访问边界。

允许改变：

- CSS token、布局、间距、颜色、阴影、圆角；
- 组件拆分；
- 页面内信息层级；
- 普通用户文案；
- admin 技术详情的展示容器；
- PC 桌面布局；
- 图标和按钮样式；
- 筛选与分页的视觉呈现。

不建议引入：

- Tailwind；
- shadcn/ui；
- 完整后台框架；
- 重型状态管理；
- 外部字体依赖；
- 图像缓存新机制；
- 装饰性动画库。

### Phase 2：核心页面升级

范围：

- 长货号、长任务名、批次名称的省略与换行；
- 页面高度、滚动容器和 sticky 区域边界；

范围：

## 当前体检发现摘要

本方案基于本地页面巡检形成，主要发现：

1. 登录页已有深色科技感，但工作台偏浅色后台，两者品牌语言需要统一。
2. 管理按钮、筛选、分页过多使用浅蓝描边，削弱主生成按钮优先级。
3. 搭配服装库和生成记录功能完整，但卡片/行内操作的主次层级仍可更清晰。
4. 模特与背景页面图像优先、信息克制，可作为视觉质量参考。
5. PC 桌面宽度下需要继续关注分页、筛选、详情侧栏和长货号的稳定性。
6. 普通用户可见语言仍需继续排查技术词，尤其 `AI 置信度`、provider 名称、底层调用事实等。
