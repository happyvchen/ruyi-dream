# design/03_ux_guide/ — Agent Guide

## 职责 (Scope)

普通用户视角 UI/UX、页面信息层级、主流程交互、默认隐藏的 AI 复杂性。这里回答“用户应该看到什么、确认什么、怎么完成一组图生产”。

## 本地规则 (Local Rules)

- 前台像“拍摄任务工作台”，不是“AI 参数控制台”。
- 默认流程控制为：上传/选择服装 -> 保存默认组图方案 -> 生成/确认/导出。
- prompt、任务包、策划器、模板命中只在内部或调试模式出现。
