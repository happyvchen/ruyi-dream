# design/03_ux_guide/ — Agent Guide

## 职责

普通用户视角 UI/UX、页面信息层级和交互边界。当前前台固定三步：导入主推款、AI 智能选搭、最终成片。

## 文档索引

| 文件 | 内容 | 何时需要读 |
|---|---|---|
| `user_uiux.md` | 普通用户工作台、Prompt 维护、生成记录和状态文案 | 设计或实现前端页面时 |
| `ui_ux_unification_plan.md` | UI/UX 统一优化方案：视觉方向、控件系统、PC 桌面页面方案和验收清单 | 做前端视觉统一、组件样式重构或 PC 桌面体验优化前 |

## 本地规则

- 普通用户不看 prompt、provider 请求、底层 JSON 或模型参数。
- 用户输入使用业务语言：智能选搭要求、成片要求。
- 拍摄母版和姿势预设仅由管理员维护；普通用户不承担预设或 Prompt 配置。
- 不提供用户可见的动态剧本步骤。
- UI/UX 统一优化不得改变生成业务逻辑、后端 API、任务状态机或 provider 调用时机。
