# design/03_ux_guide/ — Agent Guide

## 职责

普通用户视角 UI/UX、页面信息层级和交互边界。当前前台固定四步：上传主推款、AI 智能选搭、分镜预览、成片。

## 文档索引

| 文件 | 内容 | 何时需要读 |
|---|---|---|
| `user_uiux.md` | 普通用户工作台、Prompt 维护、生成记录和状态文案 | 设计或实现前端页面时 |

## 本地规则

- 普通用户不看 prompt、provider 请求、底层 JSON 或模型参数。
- 用户输入使用业务语言：智能选搭要求、分镜预览要求、成片要求。
- 不提供用户可见的动态剧本步骤。
