# 产品概览

Ruyi-Dream 是面向服饰品牌视觉生产团队的 B2B AI 数字化摄影棚。用户导入主推款，系统通过 AI Stylist 理解商品并按 Lily 品牌风格确定最终造型，再通过姿势库为五个固定镜头选定动作，生成一组电商棚拍成片。

## 主流程

user：导入主推款 → AI 智能选搭 → 最终成片。

admin 与后台执行链路：导入主推款 → AI 智能选搭 → 姿势选搭 → 最终成片。user 的姿势选搭自动执行，归入最终成片内的“正在准备拍摄”，不新增可见步骤。

## 核心原则

1. 用户确认拍摄信息和结果，不写长 Prompt。
2. 输出是一组五张电商棚拍成片，不是单张自由创作图。
3. 主推款与库内搭配款必须商品级保真，搭配款服务主推款。
4. AI 智能选搭只输出最终服装、穿法、配饰和简短理由；完整套装或可独立穿着时不额外搭配，无合适商品时允许空搭配。保留可追溯 StylingPlan，不要求多候选、审美诊断或自评分。
5. 三类成片 Prompt 维护各自五镜头的景别与构图；整组共用模特与背景中的环境、照明及模特身份。姿势选搭查看商品图，结合标签与镜头要求一次初筛直接确定五个不同姿势；冻结背景、姿势、输入版本与成片规则，结果集复用。
6. 最终生成固定使用 GPT Image-2.5 Sunburst 多参考图编辑、1:1、2K、high；受当前 ToAPIs 实际上游限制，每张最多传 6 个参考图 URL，共享背景排第一，不传遮罩；多张模特/商品原图由后端确定性合成角色参考板，不丢失来源追溯。
7. 不生成分镜预览，不使用同组连续性锚点；一致性来自统一预设、同一模特、同一 StylingPlan 和固定 Prompt。

## 页面

- `AI 摄影棚`：user 三步、admin 四步，均完整执行后台姿势选搭。
- `搭配服装库`：维护真实可选搭服装。
- `姿势库`：仅 admin 可见和操作，维护动作参考原图、识别标签和选搭可用状态。
- `模特与背景`：所有登录用户查看数字模特和一张统一背景；普通 user 只读，admin 可维护。
- `Prompt 维护`：管理员维护品牌、打标、选搭、三类成片 Prompt 和可选的成片提示词优化规则。
- `生成记录`：user 复盘输入、选搭与成片；admin 额外查看姿势参考和技术审计。

0.1.0 成功标准是：用户可以完成“导入主推款 → 获得审美成立且服务主推款的造型 → 并发生成五张符合固定图位的成片 → 下载与复盘”。
