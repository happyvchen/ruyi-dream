# 产品需求

## 0.1.0 范围

Ruyi-Dream 0.1.0 面向单一客户和单一工作空间交付一套 AI 数字化摄影棚，核心流程为：

```text
主推款导入 -> AI Stylist 造型方案 -> 五镜头直接成片 -> 下载与记录复盘
```

## 必须具备

1. 主推款任务创建、图片导入和排序。
2. 搭配服装库导入、打标、归档和复核。
3. AI 智能选搭：读取主推款和 READY 搭配服装库，只输出最终服装、穿法、文字配饰和简短理由的 `StylingPlan`。完整穿着无需额外搭配，无合适商品允许空搭配，不强制多候选、审美诊断或评分。
4. 统一背景：所有登录用户可查看默认模特与一张整组背景，仅 admin 可维护。背景限定环境与光线，姿势库提供动作与表现，三类成片 Prompt 定义五镜头景别、构图与裁切。选姿势时冻结背景与成片规则，缺背景时不能开始新选择；历史母版保留兼容。
5. 成片生成：使用 GPT Image-2.5 Sunburst edits 按五个固定镜头并发生成五张 1:1、2K、high 成片。
6. Prompt 维护：admin 维护品牌信息、搭配服装图片挑选/排序、AI 打标、主推款图片挑选/排序、AI 选搭和三类成片 Prompt；每类成片 Prompt 包含五个固定镜头块。
7. 生成记录：user 复盘输入、选搭、成片和下载；admin 额外查看冻结背景与姿势参考、attempt；旧分镜与旧预设版本仅作历史兼容。
8. 归档/彻底删除：默认归档，彻底删除前展示影响预检；删除只清理目标业务对象及其内部从属数据，不沿跨对象引用反向级联。删除搭配服装不得删除引用它的生成记录或成片。

## 导入与导入体验

主推款导入和搭配服装库导入必须支持真实服装团队常见的文件组织方式：

- 选择多张散图：作为一套，货号 / 任务名默认待填写，提交前由用户确认。
- 选择一个货号文件夹：若文件夹下直接是图片，作为一套，文件夹名作为货号 / 任务名。
- 选择一个上级文件夹：若下面存在多级目录，递归识别最底层图片目录为多套，最底层目录名作为货号 / 任务名。
- 拖入多个货号文件夹：按每个货号文件夹或其最底层图片目录拆为多套。

文件选择器不提供“选择 N 个文件夹”的能力；批量导入推荐选择一个上级文件夹，或通过拖拽多个货号文件夹完成。导入前必须展示可编辑清单，并支持在清单阶段继续添加。主推款最多 8 张，搭配服装最多 6 张；已创建对象未达上限时，在图片列表末尾显示统一的虚线加号卡，允许继续添加图片。

在 `AI 摄影棚` 导入主推款阶段，顶部 `选择图片` 始终表示用本次散图新建一款待创建项，顶部 `选择文件夹` 始终表示按文件夹识别货号并新增待创建项；只有待创建卡片内部的 `新增图片` 用于补充当前货号图片。顶部入口不得在已有货号卡片时把新选择的图片或文件夹静默追加进当前货号。

导入和后续 AI 处理必须拆成用户可理解的轻量任务阶段：

- 浏览器先尽快把图片导入到统一对象存储，并由后端保存为业务草稿或入库记录；只有文件已经被系统接住后，才开始后续 AI 识别、AI 选搭或生图流程。
- 搭配服装库导入时，`导入图片 / 保存服装` 与 `AI 识别` 是两个阶段。AI 识别失败不得让用户误以为图片导入失败；已经入库的服装仍可局部重新识别、删除后重来或继续人工处理。
- 搭配服装 AI 识别成功后，后端按模型返回的图片选择结果重排保留图；未被选中的候选图按单张图片移除语义释放，若媒体无其它引用则删除对应对象存储文件。
- 批量导入和批量创建按货号 / 拍摄任务独立推进。部分失败时，成功项保留，失败项展示业务可读原因，并允许局部重试或由用户删除后重新导入。
- `AI 摄影棚` 主推款导入和 `搭配服装库` 导入复用同一套导入任务心智：刷新页面或切到其它页面后，再回到对应页面应继续显示最近未完成或刚完成的导入状态。
- 如果某一阶段仍依赖浏览器本地文件流、刷新会导致导入中断，前端必须在刷新或关闭前给出二次确认；已经进入后端保存、AI 识别或其它可恢复阶段后，不应再阻止用户切换页面。

## 明确不包含

- 不做旧单货号默认组图方案。
- 不做动态剧本步骤。
- 不做分镜预览、自动评分、自动验收或因视觉质量判断触发的自动重生；必须提供瞬时技术失败的有限自动恢复。
- 不做多租户、计费、模板市场或复杂 RBAC。

## 成功标准

用户可以用少量业务语言完成从主推款到五张成片的完整生产，并能在生成记录中复盘与下载。

## 成片提示词优化

最终成片内部可增加一次 LLM 多模态整理，user 前台三步、admin 四步，姿势选搭与提示词准备对 user 统一显示“正在准备拍摄”。管理员维护规则、显式测试和启用开关，默认关闭；一次整组调用输出五份提示词，优化正文直接用于并发生图，不增加内容校验环节。失败不静默降级，继续与重生复用冻结事实，生成记录可追溯优化前后。首版不增加独立管理平台、自动视觉评分或自动质量重生。

## 姿势库与姿势选搭

姿势库和 AI 智能选搭后的独立姿势选搭步骤仅 admin 可见和操作。user 在确认造型后点击“生成成片”，后台自动串联姿势选搭与成片，普通页面、记录和错误提示不暴露姿势选搭、Prompt 或技术日志。查看商品图片，按已确认造型、配饰与五镜头要求，结合全库标签一次初筛直接定选，不再进行二次精选；冻结每镜头姿势、理由、动作及图片，最终成片复用。五镜头选择不同姿势，背景统一提供环境与照明，构图由成片 Prompt 控制；姿势不能改变商品或模特身份。新任务必须完成此步骤，历史任务保留原链路兼容。界面与管理交互参考搭配服装库；规则和验收详见 [姿势工作流](../01_generation_flow/pose_library_workflow.md)。
