# MVP PRD

## 1. 项目目标

Ruyi-Dream 新版 MVP 是一个 B2B AI 数字化摄影棚。它服务一个单工作空间试点场景，核心闭环是：

```text
主推款上传 -> AI Stylist 造型方案 -> 生成拍摄剧本 -> 分镜预览 -> 前 5 个镜头生成成片 -> 下载与记录复盘
```

本轮大改不延续旧版“服装货号默认组图方案”的产品形态。旧版 demo 只作为工程参考，保留可复用经验，例如 RustFS、S3 兼容对象存储、媒体三层衍生图、后台任务状态恢复和技术快照。

## 2. MVP 包含

- `AI 摄影棚` 主流程页。
- `搭配服装库` 页面，用于维护真实可见的配角服饰。
- `数字模特` 只读页，当前默认一个后台维护的数字模特。
- `生成记录` 页面，记录进入 AI 阶段后的历史任务。
- 固定 `user` / `admin` 双账号角色框架；当前两个角色进入同一套普通拍摄工作台，后续 admin 增量模块必须覆盖 user 全部体验。
- 主推款散图或单文件夹上传。
- 搭配服饰散图、单文件夹或多文件夹上传。
- 上传即创建草稿记录，保存过程数据。
- 搭配服饰保存后由 Gemini 打标。
- 搭配阶段把主推款图片、Prompt 业务规则、Lily 品牌边界和当前未归档 READY 搭配服装库全量标签事实直接交给 AI Stylist；AI Stylist 返回完整 `StylingPlan`，包括主推款理解、造型方向、候选 outfit、Aesthetic Critic 诊断、选中方案、自评分数、拒绝理由和警告。
- 拍摄剧本阶段一次性生成 `ShootScript`，包含全局导演设定和 6 条结构化 ShotPlan，用户可查看但不可编辑。
- 分镜预览阶段读取当前拍摄剧本，并由 Image-2 输出一张 3x2 分镜预览图。
- 最终阶段固定按前 5 个 ShotPlan 并发生成 5 张成片。
- 每个阶段和动作都支持重新生成；重新生成创建新版本，旧版本保留但从当前工作流失效。
- 每张最终图支持单张下载。
- 生成记录展示普通详情，并把 provider request/response、ShotPlan、快照 JSON 放入技术详情。

## 3. MVP 不包含

- 用户编辑拍摄剧本。
- 用户提示词参与选搭。
- 手动搭配、搜索替换配角。
- 自动分镜业务质检。
- 鞋、包、饰品作为真实商品入库。
- 批量 ZIP 导出、平台命名和规格导出。
- 多客户 SaaS、权限、计费、模板市场。
- 注册、邀请、找回密码、成员管理、复杂 RBAC 或可配置权限组。
- 生产级 embedding / 向量检索闭环；MVP 阶段不做后端预筛选、召回排序、兼容性评分或 outfit 草案。
- 主推款长期商品库。
- 搭配服饰显式版本表。
- 视频生成执行链路。

## 4. 页面与功能

### 4.1 AI 摄影棚

五步流程：

1. 上传主推款
2. AI 智能选搭
3. 生成拍摄剧本
4. 生成分镜预览
5. 生成成片

主推款上传规则：

- 支持上传 N 张图片，最多 8 张，推荐 3-5 张。
- 支持上传一个文件夹，任务名默认取文件夹名。
- 散图上传时任务名默认使用年月日时分秒，可重名，可修改。
- 文件名保持原样，同一任务内重名需提示。
- 不做图片角色识别，排序越靠前越重要，第一张默认主视图。
- 上传或信息填写后立即创建 `GenerationTask` 草稿。

AI 智能选搭规则：

- 点击按钮后冻结当前输入版本。
- 输入给 AI Stylist：主推款图片 + 用户简短业务要求 + 当前未归档 READY 搭配服装库全量标签事实 + Lily 品牌边界 + Aesthetic Critic 维度 + 商品主角验收维度。
- 不保存完整主推款标签，但允许保存极简 `hero_visual_summary`，用于 ShotPlan 和记录复盘。
- `SourceMaterialIDs` 为当前全部可用搭配服饰；真正进入 Gemini 的是这些搭配服饰的全量标签事实卡，不传搭配服饰图片和后端排序。
- AI Stylist 返回 `StylingPlan`，不是只返回选中的搭配服饰 ID。`StylingPlan` 必须包含候选 outfit、审美诊断、选中方案、评分、拒绝理由和警告。
- 空的库内搭配允许；非法 ID、重复 ID、不可解析 JSON、选择非 READY 素材、无法解释的互斥穿搭组合视为失败。
- 主推款可见但搭配难看、沉闷、笨重、廉价、比例失衡或明显不符合 Lily 调性，也视为选搭失败，不应进入预览。
- 支持重新选搭；新 `StylingPlan` 成功后成为当前方案，并使旧拍摄剧本、旧分镜预览和旧成片失效但保留。

拍摄剧本规则：

- 系统一次性生成 `ShootScript`，包含全局导演设定和 6 条 ShotPlan。
- 用户可以查看拍摄剧本，但不能编辑。
- 如果库内搭配服饰不适合当前拍摄，系统仍正常输出拍摄剧本，但必须披露风险和建议，不得自动替换库内服饰。
- 如果生成类鞋、帽、包、首饰不合适，系统可以在拍摄剧本中调整，但必须披露调整原因。
- 支持重新生成拍摄剧本；新剧本成功后，旧分镜预览和旧成片失效但保留。

分镜预览规则：

- Image-2 根据当前拍摄剧本返回一张 3x2 分镜预览图。
- 第 6 格直接忽略，不进入最终生成。
- 支持重新生成分镜预览；新预览成功后，旧成片失效但保留。
- 分镜预览失败不影响拍摄剧本。

最终生成规则：

- 固定生成前 5 个镜头。
- 5 张最终图并发生成。
- 每张绑定对应 ShotPlan，并传入同一张分镜预览图，文本指定参考第 N 格。
- 分镜预览图只参考姿势、身位、景别、构图、背景光线和整组风格，不作为商品事实来源。
- 支持重新生成整组成片。
- 支持单张成片重生，不影响其他已成功成片。

### 4.2 搭配服装库

用于维护可被真实生成到最终图里的配角服饰。当前只支持服装类：

- 上装
- 下装
- 连衣裙/连体类
- 外套
- 套装
- 其他服装

暂不支持鞋、包、首饰、其他饰品作为真实商品入库。生成配饰必须受 Lily 品牌样本和配饰边界约束，可以为空，不能成为画面重点或特写对象，不能自动生成公文包式传统职场套装。

上传规则：

- 散图上传 = 一套搭配服饰。
- 一个文件夹 = 一套搭配服饰。
- 多个一级文件夹 = 多套搭配服饰。
- 单套服饰最多 6 张，推荐 1-3 张。
- 素材 code 默认取文件夹名或年月日时分秒。
- `code` 全局唯一，可修改；历史快照保存当时 code。
- 同一套服饰内文件名重名需提示。

状态规则：

```text
DRAFT -> TAGGING_RUNNING -> READY
DRAFT -> TAGGING_RUNNING -> TAGGING_READY
DRAFT -> TAGGING_RUNNING -> TAGGING_FAILED
DELETED
```

上传即创建草稿；点击保存才开始 Gemini 打标。打标中锁定图片集合、排序、素材 code、标签编辑和归档。低置信度、fallback 或非服装风险结果进入 `TAGGING_READY` 并显示为 `待复核`，不进入选搭候选；打标失败的素材保留，用户可重试打标或编辑后重新保存。

### 4.3 数字模特

MVP 只读展示当前默认数字模特：

- 名称
- 头像/半身/全身参考图
- 基础身体信息

主流程不提供选择，默认使用唯一模特。每次生成时保存数字模特快照，历史再次生成默认使用当时快照。

### 4.4 生成记录

生成记录只展示进入过 AI 阶段的任务，不展示普通草稿。

普通详情展示：

- 主推款输入
- 选中的搭配服饰
- 拍摄剧本
- 分镜预览
- 5 张最终结果
- 状态、耗时、生成时间

技术详情默认隐藏，包含：

- StylingPlan
- ShotPlan
- 输入快照 JSON
- provider request/response
- attempt 列表
- 错误信息

历史任务默认使用当时快照再次生成，不读取素材库或数字模特的最新状态。

## 5. 数据建模原则

- 图片文件统一进 `MediaAsset`。
- 业务对象引用媒体资产，不直接保存文件路径作为唯一事实。
- 主推款不建长期 `HeroGarment` 商品库，只属于 `GenerationTaskInputVersion`。
- 搭配服饰不做显式版本表，生成快照保证历史可复现。
- `ImageCount` 不作为强业务字段；界面需要时实时统计，未来再加 cache。
- `GenerationTask` 有权威 current status。
- 每个模型调用都有 attempt 记录。
- 最终结果按“结果批次 -> 5 个图位 -> 每图多次 attempt”建模。

建议核心对象：

- `MediaAsset`
- `StylingGarment`
- `StylingGarmentImage`
- `GenerationTask`
- `GenerationTaskInputVersion`
- `GenerationStyling` / `StylingPlan`
- `GenerationShootScript` / `ShootScript`
- `GenerationStoryboardPreview`
- `GenerationShotPlan`
- `GenerationResultSet`
- `GenerationResultImage`
- `GenerationResultAttempt`
- `ModelProfileSnapshot`
- `GenerationInputSnapshot`

## 6. 验收标准

新版 MVP 完成标准：

1. 能上传并保存搭配服饰，完成 AI 打标。
2. 能上传主推款并创建 AI 摄影棚任务。
3. 能把全量 READY 搭配服饰标签事实直接交给 AI Stylist，并产出可解释且审美成立的 `StylingPlan`。
4. 能生成可查看不可编辑的拍摄剧本。
5. 能生成分镜预览。
6. 能按前 5 个镜头并发生成最终图。
7. 能单张下载最终图。
8. 能在生成记录中复盘输入、选搭、拍摄剧本、分镜预览、结果和技术详情。
