# AI Stylist 审美质量门

## 1. 背景

智能选搭的目标不是“选出可穿且不遮挡主推款的衣服”，而是为主推款生成一套品牌可采用的电商棚拍造型。一次选搭即使让主推款清楚可见，只要整套造型显得沉闷、廉价、笨重、比例失衡或不符合 Lily 调性，也应判定为失败。

白色高腰阔腿裤案例暴露了这个问题：AI 选择深棕针织衫、深棕西装外套、焦糖鞋包来搭配白色阔腿裤，并在文字上说明上衣塞腰、外套敞开、腰部环扣可见。这个方案通过了商品可见性检查，但实际视觉效果上半身沉重、色块生硬、季节感偏厚、裤子的轻盈高级感被压住，是“逻辑正确但审美失败”的选搭。

因此新版选搭必须增加 `Aesthetic Quality Gate`。它不是一组僵硬规则，而是 AI Stylist 必须完成的审美批判任务；同时必须读取候选漏斗和 Lily 官方品牌样本证据，不能只用通用职场搭配常识补全 Lily 风格。

## 2. 质量目标

一套选搭必须同时通过三类目标：

| 目标 | 必须回答的问题 | 失败表现 |
|---|---|---|
| 审美成立 | 这套穿在模特身上是否高级、舒服、比例协调？ | 沉闷、笨重、显矮、色块硬、季节感冲突 |
| 品牌成立 | 是否符合 Lily 的商务时装、轻松高级、现代简洁、女性化剪裁和多场景职场表达？ | 过老气、过普通、廉价通勤、过度模板化、无法对应官方风格证据 |
| 商品成立 | 是否让主推款更好卖，而不是只露出来？ | 主推款可见但气质被拖累，配角成为视觉故事 |

商品可见性是底线，不是充分条件。`hero_visibility_score` 高但 `aesthetic_score` 或 `brand_fit_score` 低时，不得进入预览。

## 3. Aesthetic Critic 维度

AI Stylist 在选择最终 outfit 前，必须对每个候选做以下审美诊断：

- **色彩重量**：上下身色块是否平衡；深色、浅色、亮色面积是否让主推款变高级。
- **廓形体量**：上装、外套、下装是否同时过宽、过长或过厚；是否压住模特比例。
- **腰线和比例**：主推款若依赖高腰、收腰、腰带或裤腰细节，搭配是否真正放大这些卖点。
- **季节和材质**：厚重针织、深色外套、皮革等是否与主推款的轻盈、洁净、春夏或通勤属性冲突。
- **模板化风险**：是否只是套用了“针织 + 西装 + 阔腿裤”“外套 + 连衣裙”等常见公式，而没有结合具体商品。
- **配饰存在感**：鞋、包、首饰是否必要且辅助主推款；包不能遮挡腰部、裤褶、口袋、门襟等核心区域；不应自动生成公文包式传统职场配饰。
- **品牌采用可能性**：这套是否像品牌真正会用于电商棚拍或 lookbook，是否能对应 Lily 官方样本或客户 lookbook 证据，而不是模型拼出的通勤概念图。

## 4. 输出要求

`StylingPlan.outfit_candidates[*]` 除了原有字段，还必须保存审美诊断摘要：

```json
{
  "aesthetic_diagnosis": {
    "color_weight": "深棕上装面积较大，但外套仅披肩且保持敞开，避免压住白色裤装",
    "silhouette_balance": "短上装或塞腰处理保证高腰线；避免长外套自然垂落遮挡腰部",
    "waistline_proportion": "高腰、收腰、腰带和裤腰等主推款比例卖点必须清楚可见",
    "season_material_fit": "轻薄针织可接受，厚重外套只可作为非主视觉披搭",
    "template_risk": "存在常见通勤三件套模板风险，需要预览重点检查",
    "brand_read": "克制通勤但不能显老气；应能说明接近哪类 Lily 官方造型证据"
  }
}
```

评分必须使用 0-1 区间，但不能默认给满分。除非候选几乎没有审美风险，否则 `aesthetic_score`、`brand_fit_score`、`commercial_readiness_score` 不应全部为 1。

如果 outfit 存在 `coverage_risk`、模板化搭配、外套搭强腰线主推款、配饰可能遮挡主推款等风险，即使模型给出解释，也不得给满分。风险说明必须转化为扣分或触发重新选搭。

## 5. 决策原则

### 5.1 允许空选搭

当候选库没有真正提升主推款的配角服饰时，空的 `selected_material_ids` 是优秀结果，不是失败。系统可以用低存在感的生成鞋履、耳饰或背景姿态补足画面。包和项链不是必填项；如果没有明确服务主推款的理由，应省略。

### 5.2 不硬凑完整 outfit

候选库不足时，不应为了形成完整通勤 look 强行选择西装、针织、马甲或另一件连衣裙。AI Stylist 必须能回答：

```text
不选库内搭配，是否比勉强选一套更好？
```

如果答案是是，应选择空选搭或更轻量的单件配角。

### 5.3 可见不等于好看

像白色阔腿裤这类商品，即使腰头、褶裥和裤管露出，也可能因为上半身过暗、过厚或过老气而失败。Aesthetic Critic 必须在进入预览前否决这类方案。

### 5.4 品类优先审美方向

- 连衣裙：优先单穿；外套只有在不破坏领口、腰线、裙身比例时才可选。
- 高腰阔腿裤：优先轻、短、干净的上装；外套必须谨慎，深色长外套默认高风险。
- 外套主推款：允许完整内搭和下装，但配角不能抢走外套肩线、门襟、领口和长度。
- 上衣主推款：下装应服务上衣比例和下摆展示，不应制造过强视觉故事。

## 6. 后端最低质量门

后端不把审美写死成大量 if/else，但必须有最低质量门：

- `aesthetic_score`、`brand_fit_score`、`hero_visibility_score`、`commercial_readiness_score` 任一低于阈值，不自动进入预览。
- 所有分数为满分但 `risk_notes`、`aesthetic_diagnosis` 为空时，视为低可信输出，应要求重试或降级为空选搭。
- 若选择外套搭配高腰裤、连衣裙或强腰线商品，必须说明外套如何不遮挡腰线，并在 `risk_notes` 中记录预览验收风险。
- 若候选方案包含两个以上大体量深色单品，必须说明色彩重量和廓形体量如何平衡。
- 若 `generated_accessories` 包含公文包、大体量手提包、夸张项链或可能遮挡腰线/裤褶/门襟的包，必须降分或拒绝。
- 若 `brand_fit_score` 较高，必须能在 `brand_read` 或品牌证据字段中说明接近哪类 Lily 官方样本；仅写“高度符合 Lily”不够。

## 7. 预览验收

预览不是只检查商品是否露出，而是检查选搭是否真的成立。以下情况应阻止最终生成或触发重新选搭：

- 主推款可见，但整套 outfit 显得沉闷、老气、笨重或廉价。
- 配角服饰成为画面记忆点，主推款只是被穿在下半身或内层。
- 鞋包遮挡腰带、裤褶、口袋、门襟等核心卖点。
- ShotPlan 未按品类展示核心卖点，例如阔腿裤没有腰线和垂坠图位。
- 预览明显违背 `wearing_notes`，例如外套没有敞开或披肩，而是正常穿着遮挡腰部。

## 8. 结论

新版 AI Stylist 的质量目标是：

```text
不是选一套“能穿且能看见主推款”的搭配，
而是选一套“品牌愿意拍、用户愿意买、主推款因此更有吸引力”的搭配。
```

当候选库不能支持这个目标时，系统应主动选择空选搭或轻量方案，而不是输出一套逻辑合理但视觉难看的完整 outfit。
