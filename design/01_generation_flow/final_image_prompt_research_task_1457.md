# 最终成片 Prompt 研究结论

> 历史实验记录：本文依赖旧分镜输入。当前成片 Prompt 应按已发布拍摄母版/姿势预设和多参考图编辑输入契约重新维护，本文仅保留商品保真与失败模式参考。

## 研究背景

本结论来自任务 1457 的最终成片 Prompt 调研。研究目标是让 Image-2 把已确认分镜预览的前 5 格，稳定兑现为 5 张 1:1 电商棚拍成片。

验收基线以 [final_image_business_intent.md](final_image_business_intent.md) 为准。分镜已经确认的景别、裁切、角度、人物大小与位置、姿势、手位、走位、留白和背景关系，都属于成片阶段必须继承的导演事实。成片阶段负责把对应分镜格变成商品级成片，而不是重新导演。

## 原始失败归因

原系统把完整六宫格、模特图和商品图一起交给 Image-2，同时只给出“分镜第 N 格，镜头角色 X”这类弱文本。结果容易坍缩成常规正面全身目录图：

- 镜头 2 失去切头中近景。
- 镜头 3 失去侧背七分身中近景。
- 镜头 5 丢失正背双视图。
- 墙地接缝和分镜中的人物位置关系不稳定。

失败核心不是商品图或分镜图不可用，而是完整六宫格制造视觉竞争，弱文本又不足以约束 Image-2 不重新导演。

## 核心结论

1. 成片阶段应参考当前分镜单格，而不是把完整六宫格交给模型自行定位。
2. 当前分镜单格承担导演事实，商品图承担商品事实，模特图承担身份事实，环境图承担背景和光线事实。四类参考图职责必须互不越权。
3. Prompt 必须写入当前镜头的可见边界契约，包括画面上下边界、角度、姿势/走位、人物尺度、位置、留白和最可能坍缩方向。
4. 成片 Prompt 不需要 Gemini 动态生成。镜头规则应由系统按品类族和镜头号选择固定块。
5. 第一阶段不需要自动评分、自动验收、输出后切格、后处理、扩图、局部重绘或抽卡选择器。

## 有效规则

- 把当前分镜单格作为独立参考图输入，能显著降低其他五格对当前成片的干扰。单格裁出属于确定性输入组装，不是视觉后处理。
- 参考图职责要明确声明：模特图只锁定身份，当前分镜格锁定导演变量，商品图恢复真实商品细节，环境图提供墙面、地面、接缝和基础光线。
- 镜头契约要用最终画面可观察的边界表达。例如镜头 2 写“上缘位于嘴唇至下巴之间，眼睛、眉毛和鼻子不得出现；下缘在小腿中部，鞋和脚不得出现”。
- 同时写正向契约和最可能失败方向。镜头 3 要写侧背角度，同时禁止转回正面或退成全身图；镜头 4 要写侧正全身轻走动，同时禁止回到普通正面站姿。
- 镜头 5 需要坐标化可见几何：中线分隔、左右人物各自区域、外侧背景留白和中央 2:3 安全裁切同时成立。
- 环境图应独立输入，避免最终成片丢失墙地接缝和基础棚拍光线。
- 审美词只能辅助商业质感，不能替代镜头结构约束。

## 无效或低效规则

- 只写“参考分镜第 N 格”“严格复现构图、角度、裁切与姿势”过于抽象。
- 只传完整六宫格会让其他格持续竞争当前镜头。
- 只写“中景/近景”“全身”“侧背面”，没有画面边界和禁止项，容易回落到普通全身正面图。
- 镜头 5 只写“双视图”“中央 2:3 安全区”“人物向中心内收”不足以约束分隔位置和人物外缘。
- 堆叠“高清、高级、时尚、商业质感”等词不能修复镜头结构。
- 每次成片前动态重写 Prompt 会重新引入不稳定性。

## 黄金链路

建议的最终成片链路：

```text
已确认分镜
→ 确定性裁出当前单格
→ 按品类族选择固定成片 Prompt
→ 按镜头号启用固定镜头契约
→ 注入商品、选搭、模特、环境和用户补充事实
→ Image-2 生成单张 1:1 成片
```

Prompt 结构应保持稳定：

1. 输出规格：单张 1:1，无文字、编号、水印；镜头 5 明确为双视图目录成片。
2. 参考图职责：模特身份、当前分镜单格、商品事实、拍摄环境。
3. 当前镜头契约：景别、上下边界、角度、姿势/走位、手位、人物尺度与位置、留白、背景关系。
4. 镜头专属反例：只保留最可能出现的结构性坍缩方向。
5. 商品恢复优先级：在分镜冻结的导演边界内恢复真实商品细节。

## 系统采纳建议

- 新增或维护三类固定成片 Prompt：上装/针织/外套、裤装/半身裙、连衣裙/连体/套装。
- 每类 Prompt 内含 5 个固定镜头块，由代码根据当前镜头号选择渲染。
- 最终输入建议顺序为：模特图、当前分镜单格、商品图、拍摄环境图。
- 不保留完整六宫格给成片模型，不生成拍摄剧本，不调用 Gemini 生成成片 Prompt。
- 不引入评分、验收、因视觉质量判断自动重生、后处理或抽卡选择器作为默认链路；瞬时技术失败由任务编排有限恢复。

## 适用边界

任务 1457 覆盖了连衣裙类前 5 个成片镜头，并对最容易失败的镜头 2、3、5 做过同条件复测，足以支持“独立单格 + 可见边界契约 + 独立环境事实源”作为当前工程方向。

但该结论不是生产规模稳定率证明，也不能把连衣裙样本文案原样套给上装和下装。上装类、下装类和连衣裙类的镜头边界仍应分别沿用 [storyboard_preview_business_intent.md](storyboard_preview_business_intent.md) 与 [final_image_business_intent.md](final_image_business_intent.md) 中的业务规则。
