# 任务 1457「生成成片」Prompt Research

## 1. 研究目标与边界

本次研究只回答一个问题：怎样让 Image-2 把已确认分镜预览的前 5 格，稳定兑现为 5 张 1:1 电商棚拍成片。

验收基线以 [`final_image_business_intent.md`](./final_image_business_intent.md) 为准。分镜已经确认的景别、裁切、角度、人物大小与位置、姿势、手位、走位、留白、背景关系均属于导演事实，成片阶段不得重新导演；人物参考图只提供身份事实，商品参考图只提供商品事实，拍摄环境图只提供环境事实。

本次最多调用 ToApis 10 次，实际使用 10 次。本文验收的 `outputPath` PNG 是 Image-2 原始输出：没有视觉后处理、扩图、局部重绘、自动评分、自动重试或自动选优。系统同时生成了供 UI 使用的 preview/thumb 衍生图，但它们不参与本次验收。部分实验在输入侧把已生成的 3×2 分镜图按固定像素边界无损裁出当前单格；它不改变单格内容，也不是对输出成片的切割或后处理。

## 2. 任务样本与原始失败

- 任务：1457，主推款 126209V7906716，品类族 `one_piece`。
- 分镜预览：3:2、2496×1664，每格 832×832。
- 原系统成片输入：两张模特图 + 完整六宫格 + 三张商品图；没有拍摄环境图。
- 原系统当前镜头文本只有“分镜第 N 格，镜头角色 X”，没有当前镜头的可见边界契约。
- 原结果：5 张图都向“正面、完整人物、常规全身目录图”坍缩。镜头 2 未切头，镜头 3 未形成侧背中近景，镜头 5 丢失双视图。

失败归因不是商品图或分镜本身不合格，而是完整六宫格制造视觉竞争，同时通用弱文本不足以约束 Image-2 不重新导演。

## 3. 逐步实验

| 轮次 | 唯一主要变量 | 镜头 | 结果 | 判定 |
|---|---|---:|---|---|
| P01 | 完整六宫格 + 明确可见边界 | 2 | 成功切头并保持中近景 | 合格；证明明确边界文本有效 |
| P02 | P01 改为独立单格输入 | 2 | 构图继承更直接，墙地缝更接近分镜 | 合格；优于 P01 |
| P03 | 独立单格 + 侧背角度和上下边界 | 3 | 稳定生成侧背七分身中近景 | 合格 |
| P04 | 独立单格 + 一般化“双视图/中央 2:3” | 5 | 恢复双视图，但分隔线偏左、人物越出安全区 | 不合格 |
| P05 | 把安全区改为可见几何契约 | 5 | 分隔线位于 50%，两人收进中央 2:3 | 合格 |

## 4. 有效与无效 Prompt 规律

### 4.1 已验证有效

1. **推荐把当前单格作为独立参考图输入。** P01 证明完整六宫格配合明确边界文本也可以合格；P02 在本样本中构图继承更直接。固定裁格是无需大模型的确定性输入组装，但当前小样本不能证明它是唯一可行方案。
2. **参考图必须按职责声明。** 模特图决定身份，当前分镜格决定导演变量，商品图决定服装事实，环境图决定墙面、地面、接缝和基础光线。
3. **用最终画面能直接观察的边界描述镜头。** 例如“上缘位于嘴唇至下巴之间，眼睛、眉毛和鼻子不得出现”“下缘在小腿中部，鞋和脚不得出现”。“七分身”“中景”只能作为辅助词，不能替代可见边界。
4. **同时写正向契约和最可能坍缩方向。** 例如镜头 3 写侧背角度，同时禁止转回正面、禁止退成全身图；镜头 4 写偏左和右侧留白，同时禁止重新居中。
5. **镜头 5 使用坐标化的可见几何。** 分隔缝位于画布 50%；左右人物分别限制在 16.7%–49% 和 51%–83.3%；最外侧各 1/6 只能是背景。这比笼统的“中央 2:3 安全区”稳定。
6. **环境图独立输入。** 明确墙面与地面颜色、材质、接缝和基础光线来自环境图，能稳定保留业务要求的墙地缝。
7. **优先级简短、确定。** 商品与人物事实优先，其次是已确认分镜导演契约，最后才是商业画质提升。

### 4.2 已验证无效或不足

1. 只写“参考分镜第 N 格”“严格复现构图、角度、裁切与姿势”过于抽象。
2. 只传完整六宫格并要求模型自己定位，会让其他五格持续竞争。
3. 只写“中景/近景”“全身”“侧背面”，没有上下画面边界和禁止项，容易回落到普通全身正面目录图。
4. 镜头 5 只写“双视图”“中央 2:3 安全区”“人物向中心内收”仍不足以约束分隔位置和人物外缘。
5. 重复堆叠“高清、高级、时尚、商业质感”等审美词不能修复镜头结构，反而会稀释导演约束。
6. 让 Gemini 在每次成片前动态重写镜头 Prompt 没有必要，并会重新引入不稳定性。

## 5. 黄金 Prompt 的结构

黄金 Prompt 不是一段对所有镜头都相同的长文，而是一个稳定的公共骨架，加一段由品类族和镜头号确定的固定镜头契约：

1. 输出规格：单张 1:1、无文字/编号/水印；镜头 5 明确为双视图目录成片。
2. 参考图职责：模特身份、独立分镜单格、商品事实、拍摄环境，互不越权。
3. 当前镜头契约：景别、画面上下边界、角度、姿势/走位、手位、人物尺度与位置、留白、背景关系。
4. 镜头专属反例：只保留最可能出现的 2–4 个结构性坍缩方向。
5. 商品恢复与优先级：在分镜冻结的导演边界内，用商品图恢复真实细节。

固定镜头契约应由系统按三类品类族和 1–5 镜头号确定，不调用 Gemini。Prompt 正文继续集中维护在“Prompt 维护”页；代码只负责确定品类、镜头号、裁出单格和按顺序组装图片。

## 6. 系统方案结论

基于本次实验，建议的成片链路保持简单：

`已确认分镜 → 固定裁出当前单格 → 选择三类成片 Prompt → 注入当前镜头布尔槽位与动态商品事实 → Image-2 单次生图`

- 新增三类固定成片 Prompt：上装/针织/外套、裤装/半身裙、连衣裙/连体/套装。
- 每类 Prompt 内含 5 个固定镜头块，通过代码注入的布尔值只渲染当前块；镜头规则仍由 Prompt 维护页负责。
- 最终输入建议使用“模特图 → 当前分镜单格 → 商品图 → 拍摄环境图”。这里的单格是从输入分镜确定性裁出，不是对模型输出做自动切格；由于用户此前要求“不需要自动切格”，是否接受这项最小输入准备调整，需要在系统实施前显式确认。
- 不保留完整六宫格给成片模型，不生成拍摄剧本，不调用 Gemini 生成成片 Prompt。
- 不引入评分、验收、自动切输出、自动重试、后处理或抽卡选择器。

## 7. 研究结论的适用范围

任务 1457 已对连衣裙类 5 个镜头全部覆盖，并对最易失败的镜头 2、3、5进行了相同条件复测，各得到小样本 2/2 成功。它足以表明“独立单格 + 可见边界契约 + 独立环境事实源”在本任务中可重复，不再只是单次结果；它仍不是生产规模的稳定率证明，不能外推为所有商品、模特和品类均有相同成功率。

上装类与下装类镜头的具体边界应沿用分镜预览原始业务意图中的品类规则固化到各自 Prompt；本次没有用额外额度做跨品类真人样本验证，因此不能把任务 1457 的连衣裙裁切文案原样套给另外两类。
