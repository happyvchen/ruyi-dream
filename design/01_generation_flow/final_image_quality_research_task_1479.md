# 任务 1479：成片质感与参考职责对照研究

研究日期：2026-10-27。研究对象是黑色浅蓝花朵针织上装、暖白阔腿裤、同一数字模特及五个镜头。结论来自保存的实际请求与输出，不代表跨商品、跨时间的生产合格率。

## 结论

**本轮证据最强的因素是供应商通道。**相同六张参考图、相同提示词、相同 `2k / high / PNG / 1:1` 参数，仅将 ToAPIs 的 `gpt-image-2.5-sunburst` 改成 `gpt-image-2.5-sunburst-official`，两次输出都从明显平滑、偏插画的皮肤与面料，改善为可辨发丝、皮肤细节和针织纤维的摄影观感。

**提示词也有独立问题，但不能单独解释原来的质感下降。**关闭优化器、加强写实描述、补回上身照、提高 quality、调整参考图顺序，在原通道各生成两次，均未消除整体渲染感。优化器实际改动了镜头边界，并引入缺少商品图依据的结构描述，仍需要修正。

**原有角色分工可以生成明显更真实的结果，无需据此认定必须替换全部参考图。**本轮成功候选仍使用共享背景、独立姿势、模特身份板、两张主推款板和搭配款板。没有检验“拆掉参考板”或“预裁切姿势图”的效果，不能将这些后续改造视为本轮已验证结论。

`official` 是供应商模型标识的一部分。本实验不能证明两个通道的底层权重、推理策略、预处理或后处理差别，也不构成模型真伪鉴定。

## 提示词与参考职责

初始审计发现，镜头 1 的优化词把“头顶到大腿上部”变成“头顶到膝盖以下”；镜头 5 加入了缺少商品图支持的后口袋描述。`porcelain skin tone`、`shadowless` 等词属于需要控制的风险措辞，但本实验没有逐词消融，不能将它们单独判定为质感主因。

推荐保留的职责边界：

| 输入 | 提供的事实 | 不得带入 |
|---|---|---|
| 模特图 | 五官、发型、肤色和体态 | 与本次配饰要求冲突的耳饰等物品 |
| 主推款、搭配款图 | 材料、颜色、花型、前后结构、长度和工艺 | 参考板排版；未证实的口袋、扣件或装饰 |
| 统一背景 | 环境、墙地关系、背景颜色和可见光线 | 人物尺度与裁切 |
| 姿势图 | 动作、重心、手位、视线和表现风格 | 身份、衣服、包、背景及景别 |
| StylingPlan | 选定商品、穿法、允许的文字配饰 | 凭空修改商品结构 |
| 固定镜头 Prompt | 景别、视角、可见边界、人物尺度、镜头 5 安全区 | 重写商品事实 |

候选词明确保留自然皮肤、发丝和纤维受光，避免通过磨皮获得“干净”；将花型、下摆罗纹和裤子后片作为商品约束，将裁切写成可观察的画面上下边界。配饰保持范围有限，不能由姿势图临时决定。

I 组还将毛衣穿法改为自然放在裤腰外，保留完整下摆，且明确了包与鞋。这是组合方案验证，不是只改“真实感”一句话的消融实验；它也不是可直接照搬到所有商品的固定文本。通用实现必须从当前商品和已确认 StylingPlan 注入事实，不能硬编码这件毛衣、无后袋或特定穿法。

## 五镜头复核

| 镜头 | 本次候选观察 | 尚未满足或尚未证明 |
|---|---|---|
| 1 正面中景 | 完整头顶、上衣和下摆，大腿裁切；皮肤和绒感明显改善 | 耳饰沿用金色款，未遵守小银色耳钉；精确花型比例待商品审核 |
| 2 细节 | 切脸近景，针织、领口与下摆罗纹清楚 | 袖口呈现不完整，需按具体细节展示要求验收；背景较灰 |
| 3 侧背中景 | 保留侧背角度和完整上衣下摆，没有退成全身 | 耳饰偏差；包形及跨镜头一致性仍需复核 |
| 4 全身 | 头到鞋完整，行走姿态和灰蓝包，织物有层次 | 包的结构与镜头 3 不完全相同；动作与选定姿势的精确符合度未量化 |
| 5 双视图 | 正背两人完整，纯黑后片、完整罗纹，无明显新增后袋；目视处于中央 3:4 区域 | 背景明度与其他镜头不完全一致；中央间距、商品精确结构及整组身份一致性仍需验收 |

**判定：质感改善成立，商品级保真和整组一致性尚未全部通过。**本轮为单一针织主推款的非盲视觉评估，没有随机种子、独立人工标注或多品类重复实验。不能承诺零瑕疵，不能将 23 张成功返回等同于 23 张业务合格。

## 采纳建议及执行边界

1. 优先采用本轮效果更好的精确通道标识作为后续验证基线；保留实际请求的模型、参数和输入快照。生产切换应作为明确的实现变更处理。
2. 优化器只整理文本，不得改变原镜头边界、商品结构和已确认穿法；同时修正固定模板中的歧义。关闭优化器本身不能解决原通道的质感问题。
3. 不因本轮结论直接大改参考板或替换背景。若验证单图输入、姿势预裁切，应在同一通道、同一提示词下另做对照。
4. 验收拆分为真实质感、商品保真、镜头符合度、参考职责隔离、整组一致性。保留失败与不合格样张，不能只展示最优结果。

本研究未覆盖任务 1479 的原有成片；接管阶段未新增付费生成、未修改生产配置或业务数据，仅复核既有证据并补齐报告。接管时工作区已有参考图组装、姿势裁切、模板等改动，本报告不将这些未纳入实验的改动宣称为已验证修复，也未替它们执行或宣称回归通过。
