# AI Stylist 质量审核与历史信号

## 当前规则

AI 选搭以主推款、Lily 品牌信息和库内服装标签为依据，只输出最终方案、穿法、文字配饰与简短理由。完整穿着无需额外搭配，无合适商品可以空搭配；缺少必要服装时说明缺口。空搭配不视为失败。

`styling-plan-v2` 不要求多候选、Aesthetic Critic、自评分、审美诊断或质量信号。没有输出这些旧字段是正常状态，不能生成“缺少诊断”警告或因评分触发自动重试。后端也不通过自动改写穿法或替换候选作审美决策。

## 硬校验

- 必需字段、字段类型、数组长度、图位族枚举及空搭配原因与商品列表的一致性。
- 文件标识、商品 code 必须来自当次输入，不能重复或编造；非法 code 不静默丢弃为空搭配。
- 素材可读、候选可用、任务状态与 provider 调用成功。

格式契约异常沿用原有有限纠错重问；无合适搭配、空配饰和主观审美问题不触发自动重问。测试使用临时数据库及 mock，不调用外部 AI。

## 用户审核

用户审核搭配是否好看、符合 Lily、主推款是否突出、穿法是否自然、是否缺少必要服装。反馈用于修改品牌信息、服装标签或选搭 Prompt；不增加自动评分或审核服务。后台保留输入、渲染 Prompt、模型原始响应与最终方案用于追溯。

## 历史兼容

旧 `StylingPlan` 中的候选、评分、审美诊断、拒绝原因和 `quality_signals` 继续读取，不回填、不改写历史结果。新方案内部只有一个已选候选容器，供既有页面、姿势与成片流程读取，评分与诊断保持空。
