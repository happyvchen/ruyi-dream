# 分镜预览 Prompt 研究结论

## 研究背景

本结论来自任务 1440 的分镜预览 Prompt 调研。该任务用于验证 Image-2 是否可以在不引入动态拍摄剧本、不做后处理的前提下，直接生成 3:2、三列两行六宫格分镜预览，并稳定满足业务对镜头、姿态、商品保真和镜头 5 安全裁切的要求。

任务样本为连衣裙品类，主推款是黑色微闪烫钻吊带裙，用户补充事实为“裙摆刚过膝”，无库内搭配服装。业务验收标准以 [storyboard_preview_business_intent.md](storyboard_preview_business_intent.md) 为准。

## 核心结论

1. Image-2 可以一次直出可用的 3:2 六宫格分镜预览，但前提是 Prompt 足够精简、无冲突，并把六格镜头规则写成可观察的画面契约。
2. 分镜规则应集中在三类固定 Prompt 中维护：`assembly.storyboard_preview_top`、`assembly.storyboard_preview_bottom`、`assembly.storyboard_preview_one_piece`。代码只注入商品、选搭、模特、环境和用户补充事实。
3. 不应恢复动态拍摄剧本、动态镜头 JSON 或让 Gemini 每次改写分镜 Prompt。它们会重新引入职责漂移和镜头冲突。
4. 旧 Prompt 的主要问题不是“描述不够多”，而是重复、冲突和抽象词过多，稀释了真正重要的画面边界。
5. 镜头 5 的中央 2:3 安全裁切不能只写“中央 2:3 安全区”。自然语言控制需要更强安全余量和商品可读性约束。

## 有效规则

- 精简 Prompt 比继续堆规则更有效。删除重复纠偏和冲突条件后，镜头 2、镜头 3、墙地接缝和整体姿态都更稳定。
- 裁切规则要写成画面可见/不可见条件。例如镜头 2 应明确“眼睛、眉毛、鼻子不得出现”，而不是只写“切头”；镜头 3 应明确鞋脚不得出现，而不是只写“中近景”。
- 环境只能保留一个摄影口径。冷白墙、冷白地面、水平墙地接缝可以稳定继承；不要同时写“墙地接缝”和“无缝背景”。
- 每格只承担一个清晰商品任务：景别、画面边界、姿态机制、商品焦点和关键失败条件。过长导演说明会降低执行稳定性。
- 受控不对称要用具体动作表达，例如单腿承重、错腿、一手侧腰、一手留空、轻走动；不要依赖“高级、时尚、自然”等抽象词。
- 参考图必须按角色声明：数字模特提供身份，商品图提供商品事实，环境图提供背景和光线事实。

## 镜头 5 修正口径

镜头 5 是分镜预览里风险最高的格子。它不是只要“正背双视图在中央区域”就合格，还必须保证目录商品可读性。

完整合格条件：

1. 正面和背面两个完整全身视图都出现。
2. 两个人物都位于中央 2:3 可裁切区域内，左右外缘留出可裁切背景。
3. 两人的内侧肩膀靠近中心分隔缝，中央不能留下大块空白。
4. 人物高度足够阅读商品结构，不能为了安全区缩成小缩略图。
5. 正背视图服务主推款商品展示，不应变成装饰性版式。

Prompt 表达上，单纯写“中央 2:3 安全区”不够；需要同时写中央位置、外侧留白、人物靠近中心线、完整头脚和商品可读性。若后续加入机器质检，应优先检查镜头 5 的裁切安全和商品可读性。

## 无效或低效规则

- `请在内部检查`、`自检后输出` 等不可审计要求没有稳定收益。
- 旧纠偏段继续叠加会制造注意力竞争。
- 大量焦段、角度、厘米和相近百分比无法带来像素级控制。
- “切头”“切半头”“中景”等抽象摄影词不足以压制常见全身人像先验。
- 只写“中央 2:3 安全区”会导致人物贴边或缩小，仍可能业务失败。
- 重复堆叠品牌形容词不能修复构图、裁切和商品事实问题。

## 系统采纳建议

当前项目已经采用更简单的最终方案：删除动态剧本运行依赖，改为三类固定分镜 Prompt + 代码注入动态事实。后续维护应沿用该方向：

1. 按品类族维护三类固定分镜 Prompt。
2. 后端根据 `StylingPlan.hero_understanding.shot_category_family` 确定性路由 Prompt。
3. 动态注入只包含商品事实、选搭摘要、数字模特、拍摄环境和用户补充要求。
4. 分镜结果由用户人工确认；第一阶段不引入自动评分、自动验收、自动切格或视觉后处理。
5. 若以后需要规模化稳定率，再增加六格切分检测、镜头分类检测、墙地接缝检测和镜头 5 安全区检测。

## 适用边界

本研究证明“精简固定 Prompt + 可见边界契约 + 明确参考图职责”在任务 1440 这类连衣裙分镜样本中有效，但不能外推为所有商品、模特、环境和品类都具备同等稳定率。上装、下装和连衣裙三类 Prompt 仍应以业务意图文档中的品类镜头规则为准分别维护。
