# Image-2 输入策略

当前成片模型为 GPT Image-2.5 Sunburst（`gpt-image-2.5-sunburst`），只负责视觉生成：最终成片按五个固定镜头逐张生成 1:1 成片。Image-2 不负责选搭、不负责判断商品品类、不负责动态规划镜头。

## 参考图角色

| 角色 | 用途 |
|---|---|
| `model_identity` | 数字模特身份、脸型、五官、发型轮廓、肤色和气质事实源 |
| `hero_garment` | 主推款商品事实源 |
| `styling_garment` | 被选中搭配服装商品事实源 |
| `shot_background` | 当前镜头的拍摄母版图，是 `image_urls[0]`；唯一提供场景、机位、景别、裁切、站位、人物尺度与光线，并在整图编辑中替换其中原人物和原服装 |
| `shot_pose` | 当前镜头的身体朝向、重心、肩线、手位、视线和头部朝向参考；只能在母版既定构图内生效，不改变脸、发型、景别、裁切、站位或人物尺度 |

## 最终成片输入

成片输入：当前镜头拍摄母版、当前镜头姿势参考、数字模特参考图、主推款参考图、选中搭配服装参考图、品类固定成片 Prompt、`StylingPlan` 造型摘要和成片用户要求。

## 图数预算

Sunburst 沿用现有最多 6 个 `image_urls` 的输入预算，不因模型升级扩大图数。固定 URL 顺序为：背景、姿势、模特身份参考板、主推款概览参考板、主推款补充细节参考板、搭配服装参考板。缺少某类事实时不填空位，也不使用同组成片连续性锚点。

模特参考板最多承载 2 张身份图；两个主推款参考板按已排序源图均衡承载最多 8 张；一个搭配服装参考板承载最多 6 张。参考板由后端本地确定性合成，不新增视觉事实。attempt 快照同时记录 provider 的 6 URL manifest 和每块参考板内的原始来源 manifest。

不使用遮罩或 `mask_url`。attempt 快照记录全部输入职责、来源顺序和结果集冻结的拍摄预设资产。

镜头 5 的母版必须直接呈现正背双人目录构图、中央细缝，以及两位人物完整落在中央 3:4 竖向裁切安全区内的站位。不要以姿势图或 Prompt 的另一套坐标补偿母版。
