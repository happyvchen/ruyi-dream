# Image-2 输入策略

当前成片模型为 GPT Image-2.5 Sunburst（`gpt-image-2.5-sunburst`），只负责视觉生成：最终成片按五个固定镜头逐张生成 1:1 成片。Image-2 不负责选搭、不负责判断商品品类、不负责动态规划镜头。

## 参考图角色

| 角色 | 用途 |
|---|---|
| `model_identity` | 数字模特身份、脸型、五官、发型轮廓、肤色和气质事实源 |
| `hero_garment` | 主推款商品事实源 |
| `styling_garment` | 被选中搭配服装商品事实源 |
| `shot_background` | 整组统一背景图，是 `image_urls[0]`；只提供场景与光线，不约束景别、机位、裁切或人物尺度 |
| `shot_pose` | 当前镜头独立选定的姿势原图，提供具体动作、神态与表现风格；不提供身份、服装、背景或光线，不覆盖镜头 Prompt 的景别与构图。发送前按镜头景别预裁切（上装镜头 1 保留上部 0.78、镜头 2 保留 0.45、镜头 3 保留 0.40），否则全身姿势图会把每个镜头都拉回全身构图 |

## 最终成片输入

成片输入：整组统一背景、当前镜头姿势参考、数字模特参考图、主推款参考图、选中搭配服装参考图、品类固定成片 Prompt、`StylingPlan` 造型摘要和成片用户要求。

## 图数预算

Sunburst 沿用现有最多 6 个 `image_urls` 的输入预算，不因模型升级扩大图数。固定 URL 顺序为：背景、姿势、模特身份、主推款正面、主推款背面或细节、搭配服装主图。缺少某类事实时不填空位，也不使用同组成片连续性锚点。

预算按“少而大”分配：每个角色只送一张事实图，不再合成多格参考板。多格拼版会把整块画布缩到 provider 的单图上限，单张商品图的有效像素被摊薄，身份、图案和绒面在输入端就被压掉，模型只能自行编造。实测同一商品、同一姿势下，单张事实图的针织纹理、图案边缘与面部细节都优于拼版。

主推款第 2 张按镜头选：正面镜头用细节特写，侧面与背面镜头用背面图，保证图案分布、口袋与省道等背面事实有据可依。attempt 快照记录每个输入的角色、原始 objectKey、裁切策略和输入策略版本。

不使用遮罩或 `mask_url`。attempt 快照记录全部输入职责、来源顺序和结果集冻结的背景与姿势资产。

镜头5的正背双视图、中央细缝和中央3:4竖向裁切安全区由成片 Prompt 明确控制，背景图不承载人物布局。
