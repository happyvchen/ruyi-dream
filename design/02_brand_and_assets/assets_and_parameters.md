# 素材与参数规范

## 1. 模特素材

当前 MVP 产品能力支持多数字模特，但当前阶段先维护 1 个默认数字模特。

当前系统支持的头像角度集合：

- 正脸
- 左 45 度
- 右 45 度
- 右侧 90 度
- 左侧 90 度
- 低头
- 抬头
- 背面
- 背面回头左 45 度
- 背面回头右 45 度

实现说明：

- 头像不要求上传时立即分配角度。
- 未分配角度的头像在 UI 中显示为 `未设置`。
- 同一个具体角度只能绑定一张头像。
- `front` 头像缺失时系统会提示，但当前不阻止保存。

## 2. 模特默认参数

每个数字模特当前维护以下参数：

| 字段 | 默认值建议 | 说明 |
| --- | --- | --- |
| 身高 | 170cm | 用于统一身体比例 |
| 体重 | 可选 | 用于补充身体比例描述 |
| 身型 | H型 | 当前直接录入自然语言标签 |
| 胸围 | 80cm | 可选精细参数 |
| 腰围 | 59cm | 可选精细参数 |
| 臀围 | 89cm | 可选精细参数 |
| 其它信息 | 都市、通勤、轻熟、自然、克制 | 汇总气质、发型、妆容边界等 |

## 3. 模特维护约束

- 不改变发型长度
- 不改变刘海形态
- 不生成浓妆
- 不生成夸张表情
- 不生成明显非同一人的五官
- 不让头部角度和身体姿态冲突
- 不让同一组图中身体比例明显变化
- 不复用同一个具体角度到多张头像

## 4. 服装素材

每个货号通常是一个独立文件夹。

系统当前不对服装图片做角色分类，只按上传顺序保存，并默认将第一张作为封面和主要参考图。业务上仍建议素材准备时尽量覆盖：

- 正面图
- 背面图
- 细节图
- 面料图
- 颜色图
- 3D 参考图

### 4.1 图片展示与衍生图

业务上仍把原始服装图作为商品事实来源；缩略图和预览图只服务前台浏览性能，不作为新的商品事实。

当前系统对上传素材、数字模特头像和生成结果维护三档图片：

| 档位 | 建议规格 | 用途 |
|---|---|---|
| `thumb` | WebP，长边约 240px | 列表卡片、历史缩略图、结果网格小卡片 |
| `preview` | WebP，长边约 1280px | 弹窗预览、详情查看 |
| `original` | 原始文件 | AI 输入、导出、质检、放大查看 |

规则：

- 原图必须保留，不因生成衍生图而覆盖。
- 第一张原图仍是封面和主要参考图；封面列表展示使用 `thumb`。
- 衍生图文件名跟随原图 stem，存放在同目录 `_derived/thumb/` 与 `_derived/preview/`。
- 前台展示使用稳定 `/api/media?key=...&variant=...` 路径，避免轮询时预签名 URL 变化触发重复下载和解码。
- 如果衍生图缺失，系统可回退原图显示，但这只是兼容策略，不是理想性能路径。

## 5. 服装识别字段

MVP 阶段建议保存以下字段：

| 字段 | 是否必需 | 说明 |
| --- | --- | --- |
| 货号 | 是 | 从文件夹名读取 |
| 品类 | 是 | 决定组图方案 |
| 主颜色 | 是 | 用于颜色保真 |
| 面料视觉特征 | 是 | 用于材质表现 |
| 版型 | 是 | 修身、标准、宽松 |
| 正面参考图 | 是 | 生成正面穿着效果 |
| 背面参考图 | 建议 | 生成背面图 |
| 细节参考图 | 建议 | 生成局部与保真约束 |
| 特别注意事项 | 可选 | 人工补充 |

## 6. 尺码参数

MVP 阶段不强制录入完整尺码表。

默认字段：

- 模特穿着尺码：M

必要时可补充：

- 衣长
- 袖长
- 肩宽
- 胸围
- 腰围
- 裤长
- 裙长

原则：

如果不影响生成判断，不要求用户填写。只有当衣长、裤长、裙长、收腰位置等明显影响真实穿着效果时，再人工补充。

## 7. 背景与构图参数

MVP 默认：

- 背景：白色或浅灰
- 光线：柔和棚拍光
- 比例：1:1
- 输出：1200x1200 或 2000x2000
- 人物占比：接近目标品牌 历史主图
- 风格：干净、通勤、商品优先

可编辑项：

- 背景：白色 / 浅灰
- 构图倾向：全身偏多 / 半身偏多 / 平衡
- 气质：通勤冷感 / 自然亲和 / 轻熟高级

## 8. 生成保真约束

所有生成都应遵守：

- 不改变服装品类
- 不改变主颜色
- 不改变面料视觉特征
- 不改变纽扣数量
- 不改变口袋位置
- 不改变领型
- 不改变袖长、裤长、裙长
- 不添加无关图案
- 不添加无关 logo 或文字
- 不让背景抢戏

## 9. 输出命名

建议输出目录：

```text
outputs/
  货号/
    01-首图.jpg
    02-全身搭配.jpg
    03-侧身版型.jpg
    04-背面.jpg
    05-局部细节.jpg
```

实际开发时可以附加生成时间：

```text
outputs/
  125329C0908714/
    2026-05-06-1530/
      01-首图.jpg
      02-全身搭配.jpg
      03-侧身版型.jpg
      04-背面.jpg
      05-局部细节.jpg
```
