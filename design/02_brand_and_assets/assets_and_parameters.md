# 素材与参数规范

## 1. 模特素材

当前 MVP 产品能力支持多数字模特，但当前阶段先维护 1 个默认数字模特。

当前默认模特头部图包路径：

`/Users/fushuai/Desktop/项目/Lily/Face-01`

当前图包包含：

- 正脸
- 左右 45 度
- 右侧 90 度
- 低头
- 抬头
- 背面
- 回头角度
- 3x3 角度合集

## 2. 模特默认参数

每个数字模特建议维护以下参数：

| 字段 | 默认值建议 | 说明 |
| --- | --- | --- |
| 身高 | 170cm | 用于统一身体比例 |
| 体型 | 标准偏瘦 | Lily 通勤女装常用模特比例 |
| 肩宽 | 标准 | 避免西装、马甲肩线漂移 |
| 腿长比例 | 标准偏长 | 用于裤装和裙装 |
| 肤色 | 自然白皙 | 与当前头部图协调 |
| 发型 | 短发、有刘海 | 必须保持一致 |
| 表情 | 自然、克制 | 避免夸张笑容 |
| 气质 | 都市、通勤、轻熟 | 对齐 Lily 调性 |

## 3. 模特禁止项

- 不改变发型长度
- 不改变刘海形态
- 不生成浓妆
- 不生成夸张表情
- 不生成明显非同一人的五官
- 不让头部角度和身体姿态冲突
- 不让同一组图中身体比例明显变化

## 4. 服装素材

服装图包路径：

`/Users/fushuai/Desktop/项目/Lily/AI单品测试对接`

每个货号通常是一个独立文件夹。

系统应尽量从文件夹中识别：

- 正面图
- 背面图
- 细节图
- 面料图
- 颜色图
- 3D 参考图

## 5. 服装识别字段

MVP 阶段建议保存以下字段：

| 字段 | 是否必需 | 说明 |
| --- | --- | --- |
| 货号 | 是 | 从文件夹名读取 |
| 品类 | 是 | 决定组图方案 |
| 主颜色 | 是 | 用于颜色保真 |
| 面料视觉特征 | 是 | 用于材质表现 |
| 版型 | 是 | 修身、标准、宽松 |
| 正面参考图 | 是 | 生成正面穿着效果 |
| 背面参考图 | 建议 | 生成背面图 |
| 细节参考图 | 建议 | 生成局部与保真约束 |
| 特别注意事项 | 可选 | 人工补充 |

## 6. 尺码参数

MVP 阶段不强制录入完整尺码表。

默认字段：

- 模特穿着尺码：M

必要时可补充：

- 衣长
- 袖长
- 肩宽
- 胸围
- 腰围
- 裤长
- 裙长

原则：

如果不影响生成判断，不要求用户填写。只有当衣长、裤长、裙长、收腰位置等明显影响真实穿着效果时，再人工补充。

## 7. 背景与构图参数

MVP 默认：

- 背景：白色或浅灰
- 光线：柔和棚拍光
- 比例：1:1
- 输出：1200x1200 或 2000x2000
- 人物占比：接近 Lily 历史主图
- 风格：干净、通勤、商品优先

可编辑项：

- 背景：白色 / 浅灰
- 构图倾向：全身偏多 / 半身偏多 / 平衡
- 气质：通勤冷感 / 自然亲和 / 轻熟高级

## 8. 生成保真约束

所有生成都应遵守：

- 不改变服装品类
- 不改变主颜色
- 不改变面料视觉特征
- 不改变纽扣数量
- 不改变口袋位置
- 不改变领型
- 不改变袖长、裤长、裙长
- 不添加无关图案
- 不添加无关 logo 或文字
- 不让背景抢戏
