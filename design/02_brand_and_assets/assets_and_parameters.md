# 素材与参数

## 媒体资产

所有上传图片统一入 `media_assets`，对象存储使用 S3 兼容接口。后端生成 `thumb` 和 `preview` 派生图用于列表和弹窗，AI 输入和下载保留原图。

媒体对象 key 按不可变资源处理：已登记的 `object_key`、`thumb_key` 和 `preview_key` 不得被不同图片内容覆盖。替换、重新上传、重新生成、重新派生图片时必须生成新 key 并更新数据库引用；只有明确删除且引用计数为 0 的媒体才释放对象存储文件。该约束是浏览器 HTTP 缓存成立的前提，避免用户因缓存看到旧图。

每套服装的正式图片包最多保留 15 张。上传暂存阶段可以接收超过 15 张，但保存为业务资产前必须完成确定性预处理并自动剔除超出上限的图片；超出上限的图片不进入正式 `media_assets` / 业务关系。预处理优先剔除解码失败、格式不支持、重复、明显低质量和非真实商品事实图。

## 上传归组规则

`AI 摄影棚` 主推款和 `搭配服装库` 导入共用同一套用户心智：用户选择散图、一个货号文件夹、一个包含多个货号的上级文件夹，或拖入多个货号文件夹；系统在创建前展示可编辑的待导入清单。

- 散图合并为一套，货号 / 任务名默认为待填写，用户提交前需要确认。
- 一个直接包含图片的文件夹作为一套，文件夹名作为货号 / 任务名。
- 一个上级文件夹下存在多级目录时，系统递归扫描，凡是直接包含图片且其子目录不再包含图片的最底层图片目录，作为一套，目录名作为货号 / 任务名。
- 不提供“选择 N 个文件夹”的文件选择器能力；如需一次处理多个货号，用户选择一个上级文件夹，或拖入多个货号文件夹。
- 如果某个目录自己有图片，子目录里也有图片，视为混合结构；前台必须在待导入清单中标记异常，由用户确认拆分或调整，不应静默猜测。
- 非图片文件不进入图片包；前台应提示已忽略的非图片文件数量。
- 待导入清单允许继续添加，每次添加仍按同一规则归组并追加到清单。
- 一旦创建为 `GenerationTask` 或 `StylingGarment`，不再提供继续添加文件夹并拆成新套的能力；如需新增货号，应回到导入入口重新创建。
- 暂存阶段可以超过 15 张；超过 15 张的套必须标红，文案说明正式上传 / 保存时会按确定性预处理自动剔除超出上限的图片。

## 主推款

主推款图片挂在 `generation_task_images`。进入 AI 阶段时创建 `generation_task_input_versions`，冻结当前图片顺序、任务名、商品信息和默认数字模特快照。

AI 摄影棚主推款上传也遵守每套最多 15 张的上限。点击 `AI 智能选搭` 时，Gemini 必须在同一次调用中完成主推款图片挑选/排序与 `styling_plan` 输出；后端保存 Gemini 返回的 `selected_files` 作为本次主推款输入版本的推荐参考图顺序，并保存完整 request / response 快照用于追溯。

## 搭配服装

搭配服装挂在 `styling_garments` / `styling_garment_images`。Gemini 打标只负责把图片转成可追溯标签事实；AI 智能选搭读取 READY 且未归档的搭配服装标签事实。

搭配服装库必须采用一次 Gemini 调用完成图片挑选/排序与 AI 打标。Gemini 返回仅要求包含：

```json
{
  "selected_files": ["front.jpg", "back.jpg", "fabric.jpg"],
  "ai_tags": {}
}
```

`selected_files` 按推荐入库/参考顺序排列，文件标识可以是后端提供的稳定临时文件名、上传项 id 或二者组合；原则是简洁、唯一、便于后端映射。后端只接受当前请求中真实存在的文件标识，不做失败兜底：Gemini 调用失败、JSON 不可解析、缺少 `selected_files` / `ai_tags` 或引用不存在文件时，本次打标失败。

## 数字模特

数字模特参考图是人物身份事实源。分镜预览和成片必须保持同一人、脸型、五官、头型、发长、发型轮廓、刘海/碎发形态、肤色、气质和身体比例。Prompt 或 provider 默认审美不得覆盖这些事实。

## Image-2 输入角色

- `model_identity`
- `hero_garment`
- `styling_garment`
- `shoot_environment`
- `preview_grid`

参考图图号由代码按输入顺序渲染，职能解释写在 Prompt 维护模板正文。

## 当前生成参数

- 分镜预览：3:2 横版六格图。
- 最终成片：1:1 单图，固定生成分镜前 5 格。
- 成片任务包必须包含当前分镜预览图和当前格号，同时继续包含商品图和模特图。

## 配饰

鞋、包、首饰不进入搭配服装库。它们可以作为低存在感风格辅助出现在 Prompt 和生成图中，但不得遮挡主推款，不做商品级验收对象。
