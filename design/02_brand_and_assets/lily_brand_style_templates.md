# Lily 品牌调性模板库

## 1. 设计目标

品牌调性模板库不是固定鞋款库，也不是强制搭配规则。

它的目标是：

`给 Image 2 一定自由度，但把自由度限制在 Lily 真实电商图的品牌边界内。`

也就是说，模型可以自由选择合适的鞋包、姿态和微表情，但不能跑出 Lily 的真实视觉语法。

## 2.1 初始化方式

品牌调性模板库不应该在每次生图时重新推理。正确方式是：

1. 品牌初始化时，对历史真实摄影图做一次集中分析。
2. 把分析结果沉淀为结构化模板、标签和参考图索引。
3. 后续每次生成只做模板检索和调用。
4. 当 Lily 调性变化或新增季节/系列时，再重新分析或人工维护模板。

初始化时建议由视觉推理模型辅助完成，人工再确认关键结论。它的输出不是 prompt，而是长期可复用的模板资产。

## 3. 可行性判断

这个想法可行，而且比鞋履白名单更合理。

原因：

1. Lily 的鞋包不是单一固定款，而是一套风格边界。
2. 不同服装品类、季节、裙裤长度，会自然匹配不同鞋包。
3. 如果把鞋写死，会让图变机械，且不一定适配每件衣服。
4. 如果完全放开，模型又会生成老气职业鞋、夸张高跟、运动鞋等跑偏结果。
5. 最好的方式是：从真实图库中抽象规则，再用参考图和短文本边界约束模型。

## 4. Lily 调性规则

### 4.1 整体气质

- 都市
- 通勤
- 年轻但不幼
- 松弛但不随便
- 得体但不传统职业装
- 轻熟、清醒、自然
- 商品优先，模特不抢戏

### 4.2 背景与光线

- 白色、浅灰、浅冷灰背景为主
- 棚拍或极简室内感
- 光线柔和
- 阴影干净
- 不做强戏剧光
- 不做复杂外景

### 4.3 姿态语法

允许：

- 自然站立，重心偏移
- 轻微侧身
- 走动感
- 一手插袋
- 一手叉腰
- 手自然垂落
- 手拿小包
- 头部轻微转向
- 背面对照

避免：

- 站军姿
- 双手僵直贴腿
- 夸张时装 pose
- 过度扭腰
- 过度张腿
- 情绪化表演姿势
- 网红摆拍感

### 4.4 鞋包调性

允许 Image 2 自由选择，但必须在以下气质内：

- 简洁
- 轻松
- 都市
- 低存在感
- 与商品颜色和季节协调
- 不抢服装主体

常见方向：

- 低跟凉鞋
- 平底凉鞋
- 乐福鞋
- 简洁单鞋
- 轻量短靴
- 细带低跟鞋
- 极简手提包
- 小号肩包

避免：

- 老气职业尖头鞋
- 夸张高跟鞋
- 运动鞋
- 厚底潮鞋
- 大 logo 包
- 宴会感亮面鞋
- 复杂绑带鞋
- 过强装饰感配饰

注意：这里不是白名单，而是品牌边界。系统应优先通过真实参考图约束，而不是只靠文字列举。

## 5. 产品抽象

新增入口：

`品牌调性模板`

MVP 阶段可以内置一个默认模板：

`Lily 默认电商棚拍调性`

模板包含：

```json
{
  "templateId": "lily-default-ecommerce",
  "name": "Lily 默认电商棚拍调性",
  "sourceFolders": [
    "2D专供-17款-0410",
    "3A专供-18款-0410",
    "3C专供-36款-0417",
    "3C专供单色款-91款-0420",
    "3D专供剩余-16款-0427"
  ],
  "stylePrinciples": [
    "都市通勤",
    "年轻轻熟",
    "克制松弛",
    "商品优先",
    "白/浅灰棚拍"
  ],
  "poseBoundary": {
    "allow": ["重心偏移", "轻微侧身", "走动感", "插袋", "叉腰", "手拿小包"],
    "avoid": ["站军姿", "夸张时装姿势", "网红摆拍"]
  },
  "stylingBoundary": {
    "allowMood": ["简洁", "轻松", "都市", "低存在感"],
    "avoid": ["老气职业尖头鞋", "夸张高跟", "运动鞋", "厚底鞋", "大logo包"]
  }
}
```

模板不是给 Image 2 直接长篇阅读的说明书，而是给 `组图策划器` 使用的生产资产。策划器会根据当前服装品类和镜头类型，从模板中选择参考图、Pose、鞋包边界和短文本禁止项。

## 6. 模板在生图中的使用方式

不要在 prompt 里长篇写鞋包规则。

推荐方式：

1. 从模板库中按品类挑选 3-6 张真实参考图。
2. 把这些图作为 `Brand Style References` 输入给 Image 2。
3. 文本只写一句边界：

```text
Use the Lily real-photo references as the brand-style boundary for pose, footwear, bags, accessories, lighting, background, and composition. Choose styling freely only within this visual language.
```

如果某个品类有强相关参考，例如连衣裙，就优先选连衣裙真实图，而不是全品类混合图。

生产链路：

```text
历史真实图 -> 品牌初始化分析 -> Lily 模板库
当前货号 -> 判断品类 -> 检索同品类模板和参考图
组图策划器 -> 生成每张图的 styling 边界
Image 2 -> 按参考图和短文本生成
```

## 7. 模板库的数据结构

建议把每张真实图打上标签：

- 品类
- 图位：首图/半身/侧身/背面/局部
- pose
- 鞋履类型
- 是否有包
- 背景
- 构图
- 人物占比
- 季节感
- 可作为参考的强度

示例：

```json
{
  "image": "real/002.webp",
  "category": "连衣裙",
  "shotType": "侧身全身",
  "pose": "侧身走动感",
  "footwear": "黑色轻量凉鞋",
  "bag": "无",
  "composition": "3:4竖版，全身",
  "styleTags": ["松弛", "年轻", "通勤", "商品优先"],
  "referenceUse": ["pose", "footwear", "composition"]
}
```

## 8. 对产品界面的影响

`生成组图` 页面中，不应该出现复杂鞋履选择器作为默认流程。

建议改为：

- 品牌调性模板：默认 `Lily 默认电商棚拍调性`
- 参考图策略：自动按品类匹配
- Styling 自由度：低 / 标准 / 高

MVP 默认：

- 品牌调性模板：Lily 默认电商棚拍调性
- 参考图策略：同品类优先
- Styling 自由度：标准

只有当用户发现搭配跑偏时，再允许用户加一句补充要求，或者手动选几张参考图。

## 9. 与鞋包问题的关系

鞋包不符合品牌，不应该通过固定鞋履白名单解决，也不应该完全交给 Image 2 自由发挥。

更稳的做法是：

- 品牌模板库提供 Lily 鞋包气质边界。
- 同品类真实图提供具体视觉参考。
- 组图策划器选择适合当前服装的搭配方向。
- Image 2 只在这个边界内做视觉生成。

例如当前黑色短款无袖连衣裙，策划器应优先选择：

- Lily 连衣裙全身参考图
- 轻便黑色凉鞋/低跟单鞋/简洁乐福鞋参考
- 松弛通勤姿态参考
- 白/浅灰棚拍构图参考

而不是把所有历史图混成一个大参考板，也不是在 prompt 中写很长的鞋履说明。
