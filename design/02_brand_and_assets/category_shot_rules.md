# Lily 品类图位规则

本文件是三类固定成片 Prompt 的业务规则来源，不是动态镜头计划 schema。各镜头的景别、视角与安全区写入 Prompt；独立姿势图提供动作，整组共享背景图提供环境与光线，不再维护拍摄母版。

## 通用要求

- 姿态体现时尚、高级、自信、冷酷、现代、精致、优雅、魅力。
- 品牌表现用于选择适配姿势；选定后保持具体动作和表情，不以通用风格词重新设计姿势。
- 避免夸张扭腰、过度张腿、网红摆拍或过强表演。
- 背景与光线以本次冻结的统一背景图为准，推荐白/浅灰商业棚拍。
- 镜头 5 为 1:1 方形双视图目录构图，左右人物靠近中心线，并完整位于中央全高 3:4 裁切窗口（横向 12.5%–87.5%），内容安全边界为 15%–85%；正背人物中心约在整图的 33%/67%，完整轮廓含手脚、衣物与包均不越界，空间不足时等比缩小并移位，不改变身体比例或衣物长度。中央为极细的纯白（#FFFFFF）竖直隔带，贯穿全高，不接收阴影或反射；两侧环境一致不等于跨白缝连续成景。这是单视图禁止拼图规则的明确例外，不增加第三格。

## 上装 / 针织 / 外套

1. 七分身正面中景：头顶到大腿上部，上衣从领口到下摆完整入画。
2. 衣服细节：近景特写，切脸或无头，聚焦领口、门襟、扣子、袖口和面料肌理。
3. 上半身不同角度中景：侧身或 3/4 背面，展示肩线、侧缝、后片轮廓和衣长。
4. 全身穿搭：完整展示上衣、下装和鞋，模特占画面高度约 82%-88%。
5. 通用双视图目录构图。

## 裤装 / 半身裙

1. 下半身正面中景：腰部到脚，下装完整。
2. 衣服细节：腰头上方少量余量至大腿中段，腰头完整，下装为主体；头、颈肩胸、膝和鞋在画外。只展示实际存在的腰头、门襟、口袋、褶位和面料。
3. 下半身不同角度中景：侧/背角度，上缘腰部以上、下缘小腿中部，展示侧缝、后片与轮廓。长裤裤脚和鞋在画外，较短裙摆按真实长度可入画；靠取景裁切，不延长裤腿遮鞋。
4. 全身穿搭：完整 outfit，模特占画面高度约 82%-88%。
5. 通用双视图目录构图。

## 连衣裙 / 连体 / 套装

1. 全身正面全景：裙摆/裤脚完整，模特占画面高度约 82%-88%。
2. 七分身侧正面中近景：切去头部或保留嘴巴以下，下缘低于裙摆。
3. 七分身侧背面中近景：切半头，下缘低于裙摆，展示背部剪裁与摆量。
4. 全身侧正面全景。
5. 通用双视图目录构图。

## 姿势参考的画面适配

镜头1–4均为单人单视图，镜头4的完整全身也只呈现一个人物。镜头5才呈现同一模特正背双视图。姿势标签以通用的画面布局、视图组合、参考景别和视图说明分别描述原图；镜头5须区分正背、正侧、双正面及三视图。选姿规则与历史标签补录见 `../01_generation_flow/pose_library_workflow.md`。
