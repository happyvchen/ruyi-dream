# Lily 品类图位规则

本文件是 15 个拍摄预设槽位和三类固定成片 Prompt 的业务规则来源。它不是动态镜头计划 schema；每条规则对应一个需要提前维护背景、遮罩和姿势图的固定镜头。

## 通用要求

- 姿态体现时尚、高级、自信、冷酷、现代、精致、优雅、魅力。
- 避免正对镜头、双臂僵直贴腿的立正/证件照感。
- 避免夸张扭腰、过度张腿、网红摆拍或过强表演。
- 背景为白/浅灰棚拍，可见轻微墙地缝。
- 镜头 5 为 1:1 方形双视图目录构图，左右人物靠近中心线，并完整位于中央 2:3 安全裁切区。

## 上装 / 针织 / 外套

1. 七分身正面中景：头顶到大腿上部，上衣从领口到下摆完整入画。
2. 衣服细节：近景特写，切脸或无头，聚焦领口、门襟、扣子、袖口和面料肌理。
3. 上半身不同角度中景：侧身或 3/4 背面，展示肩线、侧缝、后片轮廓和衣长。
4. 全身穿搭：完整展示上衣、下装和鞋，模特占画面高度约 82%-88%。
5. 通用双视图目录构图。

## 裤装 / 半身裙

1. 下半身正面中景：腰部到脚，下装完整。
2. 衣服细节：近景特写，聚焦腰头、门襟、口袋、褶位和面料。
3. 下半身不同角度中景：侧/背角度，展示侧缝、垂坠、裤脚或裙摆量感。
4. 全身穿搭：完整 outfit，模特占画面高度约 82%-88%。
5. 通用双视图目录构图。

## 连衣裙 / 连体 / 套装

1. 全身正面全景：裙摆/裤脚完整，模特占画面高度约 82%-88%。
2. 七分身侧正面中近景：切去头部或保留嘴巴以下，下缘低于裙摆。
3. 七分身侧背面中近景：切半头，下缘低于裙摆，展示背部剪裁与摆量。
4. 全身侧正面全景。
5. 通用双视图目录构图。
