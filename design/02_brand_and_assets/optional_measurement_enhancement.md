# 尺寸可选增强模块

## 1. 背景

“裙长和裙摆比例错误”不能只靠 prompt 解决。

图片能提供视觉参考，但当模型把服装穿到新身体上时，仍然可能误判：

- 裙长
- 裤长
- 衣长
- 袖长
- 肩线
- 腰线
- 下摆宽度
- 褶边露出高度

这些问题本质上是 `服装尺寸` 和 `模特尺寸` 的映射问题。

因此产品应设计一个可选的尺寸增强模块：

`不填尺寸也可以生成；填写尺寸后，生成更精准。`

## 2. 模块原则

- MVP 不强制用户填写。
- 有尺寸信息时，优先于文本语义。
- 尺寸不替代服装图，而是帮助模型理解穿着比例。
- 尺寸字段只在影响视觉结果时使用。
- 当前暂无尺寸信息时，先完成产品结构设计，暂不验证。

## 3. 模特尺寸字段

### 3.1 基础字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 身高 | 可选，建议填 | 影响衣长、裙长、裤长 |
| 体重 | 可选 | 辅助判断体型 |
| 肩宽 | 可选 | 影响上衣、西装、马甲 |
| 胸围 | 可选 | 影响上衣、连衣裙 |
| 腰围 | 可选 | 影响裤裙腰线 |
| 臀围 | 可选 | 影响裤子、半裙、连衣裙 |
| 腿长 | 可选 | 影响裤长和裙长视觉 |
| 臂长 | 可选 | 影响袖长 |

### 3.2 视觉简化字段

如果没有精确三围，可用简化字段：

- 身高：例如 170cm
- 体型：偏瘦 / 标准 / 微曲线
- 肩宽：窄 / 标准 / 宽
- 腿长比例：标准 / 偏长

## 4. 服装尺寸字段

按品类显示，不要一张大表。

### 4.1 连衣裙

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 尺码 | 可选 | 模特穿着尺码 |
| 衣长 | 强建议 | 决定裙长 |
| 肩宽 | 可选 | 无袖/有袖都可能影响肩线 |
| 胸围 | 可选 | 决定松量 |
| 腰围 | 可选 | 决定腰线和松紧 |
| 下摆围 | 强建议 | 决定裙摆宽度 |
| 褶边露出高度 | 强建议 | 决定拼接/下摆露出 |

### 4.2 半裙

- 裙长
- 腰围
- 臀围
- 下摆围
- 开衩高度
- 褶量

### 4.3 裤子

- 裤长
- 腰围
- 臀围
- 大腿围
- 脚口围
- 前后裆长

### 4.4 上衣/外套/马甲

- 衣长
- 肩宽
- 胸围
- 袖长
- 下摆围
- 腰围或收腰位置

## 5. 从尺寸推导视觉约束

尺寸不要原样塞进 prompt，而要转换成视觉语言。

示例：

```json
{
  "modelHeight": 170,
  "garmentLength": 82,
  "visualLength": "膝上中段",
  "hemWidth": "轻A字，不是大伞摆",
  "ruffleExposure": "下摆蓝白褶边露出约8cm"
}
```

生成时文本只写视觉约束：

```text
Use the provided measurements to keep the wearing length and hem width accurate. The dress should fall at mid-thigh / above-knee according to the selected model, with restrained slight A-line width and narrow visible striped ruffle layer.
```

## 6. 产品界面设计

在服装识别卡中增加折叠区：

`尺寸增强（可选）`

默认收起。

文案：

`不填写也可以生成；填写后可更准确控制衣长、裙长、裤长、袖长和廓形比例。`

字段按品类动态出现。

### 连衣裙示例

- 模特身高
- 模特穿着尺码
- 衣长
- 下摆围
- 褶边露出高度
- 期望穿着长度：自动推导，可人工改
- 期望裙摆宽度：自动推导，可人工改

## 7. 本款 125309C7948510 的理想字段

当前没有真实尺寸，暂无法验证。但如果后续能拿到尺寸，本款最关键字段是：

- 模特身高

## 8. 优先级

生成优先级应为：

1. 服装图像事实
2. 尺寸增强参数
3. Lily 品牌调性参考
4. 单张镜头任务
5. 文本补充要求

尺寸参数一旦填写，应高于普通文本描述。
