# Lily 品牌调性模板库

## 1. 设计目标

品牌调性模板库不是固定鞋款库、固定 pose 库，也不是长 prompt 模板。

它的目标是：

```text
把 Lily 官方实拍模特图中的姿态、取景、鞋包、光线和构图沉淀为可检索的生产资产。
```

Image-2 可以在边界内生成鞋包、配饰和微表情，但不能跑出 Lily 官方电商图的真实视觉语法。AI Stylist 和 ShotPlan 生成器必须先检索同品类官方样本，再决定造型、穿法和图位。

## 2. 样本来源

可进入模板库的来源必须可验证：

- Lily 中国官网与海外官方店公开商品图。
- Lily 官方天猫 / 淘宝店铺公开商品图、分类页和商品标题。
- Lily 官方微博、小红书、抖音等公开内容。
- 试点客户提供并确认可作为品牌基准的 lookbook、历史棚拍图和人工选搭参考。

样本不只保存“好看的图”，还要保存它为什么可复用：品类、图位、取景、姿态、穿法、鞋包和适用边界。

## 3. 官方样本观察

当前 Lily 官方样本中稳定出现的视觉语法：

- 背景：白色、浅灰、浅冷灰、少量极简室内/米色墙面。
- 光线：柔和均匀，轻微落地阴影，商品边缘清楚。
- 画面气质：都市、通勤、年轻但不幼、轻熟、松弛但得体。
- 姿态：轻斜正、重心偏移、错腿、插袋、自然垂手、轻走动、侧身转体。
- 鞋包：低存在感低跟鞋、凉鞋、乐福鞋、短靴、小号手提/手拿/肩包；包不应挡商品结构。
- 构图：全身图建立比例，局部图解释卖点；不同品类有不同取景组合。

不应作为标准：

- 站军姿、双手僵直贴腿。
- 强写真感、强街拍感、复杂外景或戏剧光。
- 大号公文包、大体量托特包、夸张首饰、过度抢眼鞋履。
- 把所有品类都做成多张全身图。
- 用搭配服饰局部近景抢主推款。

## 4. 姿态边界

允许：

- 自然站立，重心偏移。
- 轻微侧身或 3/4 斜正。
- 一腿轻微前置，展示裤腿/裙摆。
- 单手或双手插袋，前提是不遮挡主推款关键结构。
- 手自然垂落。
- 轻走动，动作幅度克制。
- 头部轻微转向。
- 背面或侧身补充版型。

避免：

- 站军姿。
- 双手僵直贴腿。
- 夸张时装 pose。
- 过度扭腰、过度张腿。
- 情绪化表演姿势。
- 网红摆拍感。

## 5. 鞋包与配饰边界

鞋包不是 MVP 商品事实源，只能作为生成配饰。

允许方向：

- 简洁低跟凉鞋、细带凉鞋、浅口鞋、乐福鞋、轻量短靴。
- 黑、米、棕、裸色、低饱和浅色等低存在感颜色。
- 小号手提包、手拿包、小号肩包、编织小包。
- 小耳饰、手表、细手链；项链只有在领口图位需要时低存在感出现。

避免方向：

- 老气职业尖头鞋。
- 夸张高跟鞋、厚底潮鞋、运动鞋。
- 大 logo 包。
- 宴会感亮面鞋。
- 复杂绑带鞋。
- 大号公文包、商务手提公文包、大体量托特包。
- 抢主体的首饰。

## 6. 穿法边界

穿法必须由服装结构支持，不能为了露出主推款卖点硬改穿着方式。

裤装主推款：

- 腰头、门襟、裤褶、裤长和裤脚关系是核心。
- 可用短上装、薄衬衫、T 恤、薄针织、短马甲、自然下摆或半塞来露出腰线。
- `tucked` 只适合柔软、薄、无厚重门襟和下摆堆量风险的上衣。
- 开衫、外套、厚针织、有明显门襟/纽扣/镂空下摆的上衣默认禁止全塞。

上衣主推款：

- 不能用腰带、大包或复杂下装抢上衣。
- 外套不能遮住领口、下摆和袖型。

连衣裙主推款：

- 多数情况下可空库内搭配，只用低存在感鞋包补足场景。
- 外套必须敞开或轻量，不能遮腰线和裙摆。

## 7. 产品抽象

默认品牌模板：

```json
{
  "templateId": "lily-official-ecommerce",
  "name": "Lily 官方电商棚拍调性",
  "stylePrinciples": [
    "都市通勤",
    "年轻轻熟",
    "克制松弛",
    "商品优先",
    "白/浅灰棚拍"
  ],
  "sampleStrategy": {
    "categoryFirst": true,
    "shotTypeFirst": true,
    "minSamples": 3,
    "maxSamples": 6
  },
  "poseBoundary": {
    "allow": ["重心偏移", "轻微侧身", "轻走动", "插袋", "错腿", "自然垂手"],
    "avoid": ["站军姿", "夸张时装姿势", "网红摆拍"]
  },
  "stylingBoundary": {
    "allowMood": ["简洁", "轻松", "都市", "低存在感"],
    "avoid": ["老气职业尖头鞋", "夸张高跟", "运动鞋", "厚底鞋", "大logo包", "大体量公文包"]
  }
}
```

模板不是直接丢给 Image-2 的长说明，而是给 AI Stylist、ShotPlan 生成器和 Image-2 输入组装使用的生产资产。

## 8. 模板使用方式

推荐链路：

```text
官方实拍图 -> 品类/图位/姿态/穿法/鞋包打标 -> Lily Brand Style Index
当前主推款 -> HeroUnderstanding -> 同品类同图位样本检索
AI Stylist -> StylingPlan
ShotPlan 生成器 -> 图位、取景、姿态和配饰边界
Image-2 -> 按商品事实图 + ShotPlan + 少量官方样本生成
```

不要在 prompt 里长篇写鞋包规则。应优先选择同品类、同图位、同穿法的 3-6 张官方样本作为参考，再用短文本边界说明：

```text
使用 Lily 官方样本作为姿态、鞋履、包袋、配饰、光线、背景和构图边界。造型必须服务本次主推款，不得让搭配服饰或配饰成为视觉中心。
```

如果主推款是裤装，应优先检索裤装全身、腰脚、腰膝、侧身/动态和正面颜色样本；不能混用上衣半身样本替代裤装核心图位。

## 10. 对产品界面的影响

`AI 摄影棚` 页面不应出现复杂鞋履选择器或 pose 控制台。

MVP 默认：

- 品牌调性模板：Lily 官方电商棚拍调性。
- 参考图策略：同品类、同图位优先。
- 生成配饰自由度：标准，但受低存在感边界约束。
- 技术详情中可查看品牌样本证据，普通用户默认只看推荐造型、搭配服饰和六宫格。

当用户发现搭配跑偏时，可允许补充一句业务要求或重选参考样本，但不把用户训练成 prompt 工程师。
